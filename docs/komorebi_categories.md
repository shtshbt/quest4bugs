## 1. 記載原則

1. すべてのカテゴリは「潰す弱点」を 1 行で明文化する。弱点に紐づかないカテゴリは追加しない。
2. Lv1 から 10 は難易度が単調に上がること。軸は量の増加ではなく操作の質 (想起、構造、工夫、統合、逆算、派生) で設計する。
3. 形式 (normal / formulation / ordering / diagnosis / voice) の適合をカテゴリごとに明示する。
4. 本編カテゴリ (K5CATS / K10CATS / K5DEV 30 / K10DEV 22) との重複照合を採用条件とする。
5. 投入判定信号 (2026-08-12): 「本編演習正答率が高いのに同時期の外部評価が低い」乖離を、過程層 (文章からの構造同定) の欠陥の証拠として使う。時系列が混在する比較 (外部評価が演習開始前) は乖離と見なさない — 介入進行中・再評価待ちとして扱う。データ源は juken_saito 基盤 (practice_skills.csv × skills_evidence.csv)。

## 3. カテゴリ別 Lv 設計

### 3.1 kom_ratio (割合と比)

`docs/komorebi_ratio_curriculum.md` (v0.1) を参照。三重勾配 (数学的内容 + 形式 + 思考負荷) で設計済み。

### 3.2 kom_kuku_dan2 から dan9 (段暗唱、8 カテゴリ。2026-08-12 v3 確定)

九九の連続高速想起 (段の暗唱) を主目的とする、1 段 = 1 カテゴリの 8 本群。v1 の kom_kuku_recite (単発句) と v2 の通し暗唱案はこの群へ発展的に解消した。ローリング更新で段順 (2, 5, 3, 4, 6, 7, 8, 9) に解禁する。

問題単位はチャンク (3 句 / 5 句 / 9 句)。子どもはチャンクを一息で唱え、認識はチャンク末に 1 回だけ走るため、句ごとの認識待ちでテンポが壊れない (per 句判定のカラオケ式は認識レイテンシがテンポを破壊するため棄却)。Lv 軸 = 表示の足場 × チャンク長 × テンポで、よみあげ (符号化) と想起を交互に置く:

| Lv | 表示 | チャンク | 負荷 |
|---|---|---|---|
| 1 から 2 | 式 + 答え + 句ふりがな (よみあげ) | 3 句 (×1-3 / ×4-6 / ×7-9 の 3 通りのみ) | 音読による符号化 |
| 3 から 4 | 式のみ (2×1=?) | 3 句 | 句と答えの想起 |
| 5 から 6 | 式 + 答え + ふりがな (よみあげ) | 5 句 (×1-5 / ×5-9、5 は重複) | 連鎖の符号化 |
| 7 から 8 | 式のみ | 5 句 | 想起 |
| 9 | 式のみ | 9 句通し | 想起 |
| 10 | 式のみ | 9 句通し | 想起 + スラスラテンポ (段全体 13 秒目安) |

- テンポは Lv とともに単調に上がり、タイムアップは不正解として扱う (design 2.2 決定 6 の第 2 次改訂)。安全弁 3 つ: 適応昇降が「いまのスラスラ度」へ自動で水位を合わせる (失敗は罰でなく水位測定) / 認識失敗・言い直しはノーカウント再挑戦 (design 7.4 章の 5 状態判定) / 誤答でゲージは減らない。
- タイム計測は発話終端 (音声活動の終わり) 基準とし、認識エンジンの遅延を子どもの成績に混入させない。テンポの具体秒数は仮置きとし、Phase 3 で実子テストして調整する (捕獲 pity と同じ扱い)。
- タイムバー UI (2026-08-12 確定): チャンク表示と同時に満タンのバーが減り始め、尽きる前に読み上げ終われば OK。バーは全 Lv で表示し (よみあげ Lv はゆったり)、Lv が上がるほど速く減る。見えないタイムアウトは理不尽に感じられるため不可視化しない — バーが目標の可視化とテンポガイドを兼ねる。装飾は付けない。実装は voice kind の段暗唱分岐に付随する新規 UI 部品 (本編に時間 UI は存在しない)。
- よみあげ段階の意義: 想起は符号化されていない記憶からは起きない。最初の符号化を音読 (唱和と同じ errorless 形式) で行い、直後の Lv で想起へ切り替える。読むだけでは定着しない (定着は想起が作る) が、想起の前提を作る。
- 段あたりの問題バリエーションが数通りしかないのは意図どおり (暗記カテゴリは反復が目的。pi314 Lv1 と同じ理屈)。
- 詰まった句・遅い句は無音レイテンシで検出し、kom_kuku_run の再出題デッキへ還流する。
- ゲージ: チャンク 1 本 = 1 正答。形式: voice のみ。

### 3.4 kom_pi314 (3.14 の段、2026-08-12 v2 確定版)

v1 案の Lv4 から 6 (3.14×11 から 20 の直接暗記) を棄却し、工夫計算テクニックの梯子として再設計した。確実に覚える対象は ×1 から 9 の 9 個のみ。平方数の積は暗記を強制せず、わざで素早く自作できる馴染みを目標とする (頻出の ×16 と ×25 は反復で自然に定着する)。構造は螺旋: 技 (Lv5 まとめ) を弾が少ないうちに導入して「まとめると覚えている範囲に収まる」即効を体感させ、弾 (Lv6 平方数) を増やし、技×弾 (Lv7) で往復する。

| Lv | 内容 | 操作の質 |
|---|---|---|
| 1 | 3.14×1 から 5 の想起 | 想起 |
| 2 | 3.14×6 から 9 の想起 (繰り上がり多発帯) | 想起 |
| 3 | ×1 から 9 の完全混合 | 想起の自由度 |
| 4 | 位取り: ×10、×20 から 90、×100 (31.4×n との等価を明示) | 構造 |
| 5 | まとめ入門: 3.14×a ± 3.14×b の係数を先にまとめ、×2 から 9 か ×10 に収める。まとめない場合の苦痛差が大きい数値組を優先する | 技の導入 |
| 6 | 平方数の積への馴染み: ×16、×25、×36、×49、×64、×81 を Lv4 と 5 の技で自作する | 弾の拡張 |
| 7 | まとめ発展: 差 (輪の面積型)、3 項、÷2 の係数化、まとめ先が平方数になる組 | 技×弾 |
| 8 | 逆引き: 3.14×□ = 積 (円周・面積からの逆算に対応) | 逆算 |
| 9 | 分配・展開: ×13 = ×10 + ×3 (まとめの逆向き)。31.4×n、0.314×n の小数位取り | 派生 |
| 10 | 全形式混合 | 統合 |

平方数 6 個の primary わざ (選定基準: 小数の位ずれ加算を避ける。偶数 = 倍々、奇数 = きりのいい数から調整):

| n | primary | 別の道 |
|---|---|---|
| ×16 | ×8 の 2 倍 (25.12 → 50.24) | ×10 + ×6 |
| ×36 | ×18 の 2 倍 (×9 → 56.52 → 113.04) | ×30 + ×6 |
| ×64 | ×32 の 2 倍 (×16 → 100.48 → 200.96) | ×60 + ×4 |
| ×25 | 314 の半分の半分 (157 → 78.5) | ×20 + ×5 |
| ×49 | ×50 − ×1 (157 − 3.14 = 153.86) | なし |
| ×81 | ×80 + ×1 (251.2 + 3.14 = 254.34) | なし |

偶数組は ×8 → 16 → 32 → 64 と ×9 → 18 → 36 の倍々家系、奇数組は 314 と 157 のランドマークからの調整で、覚える体系は 2 本にまとまる。

- 出題数値の分布ルール: 円の問題で現れる分布 (直径 1 から 20 相当、平方数、半円係数) に寄せる。円周・面積の文章題そのものは入れない (v1 方針維持)。
- 形式: normal のみ。診断・立式・音声は不適用 (design 7.2 章)。わざ (5 章) は足場と解説カードにのみ現れる。
- 時間要素は使用しない。

### 3.5 kom_unit_convert (単位換算、2026-08-12 v2 確定版)

v1 案 (ペア別換算の階段) を、pi314 と同型の「弾 → 原理 → 技」の 3 層に組み直した。基礎変換関係そのものの想起層と 2 乗 3 乗の原理層を新設 (基礎変換が覚わっていないという実測、および m²↔cm² が v1 の梯子から抜けていた穴に基づく)。

| Lv | 内容 | 層 |
|---|---|---|
| 1 | 面積の階段の想起: 1a = 100m²、1ha = 100a、1km² = 100ha (「面積の階段は全部 ×100」という構造ごと覚える) | 弾 |
| 2 | 体積・かさの階段の想起: 1L = 1000mL、1mL = 1cm³、1m³ = 1000L (「×1000 の階段」と mL = cm³ の橋) | 弾 |
| 3 | 2 乗・3 乗の原理: 1cm = 10mm → 1cm² = 100mm² を入口に、1m² = 10000cm²、1m³ = 1000000cm³ を作る。1cm³ = 1000mm³ の確認を含む | 原理 |
| 4 | 面積の換算 (一段。5a = □m²、300ha = □km²) | 技 |
| 5 | 面積の二段 (階段を 2 つ渡る。3km² = □a) | 技 |
| 6 | 体積・かさの換算 (一段) | 技 |
| 7 | 二段経路 (m³ → mL。4 手の経路整列はここ) | 技 |
| 8 | 逆向き (小さい単位 → 大きい単位、÷ の方向) と小数 | 技 |
| 9 | 揃えて計算: 1.2m² − 400cm² = □cm²、3ha + 500a = □a。換算が目的から手段に変わる統合段 | 統合 |
| 10 | 総合 (新出なし) | 統合 |

- 出題境界: 1 問に単位は 2 種まで。mm²・mm³ は Lv3 の原理 (2 乗の最も見えやすい入口) でのみ使い、換算ドリル (Lv4 から 8) と揃え計算 (Lv9) には入れない。受験算数で mm² は原理確認として出るが、主戦場は cm²/m²/a/ha/km² と mL/cm³/L/m³ である。3 単位混在 (m³ − cm³ = mm³ 等) は不採用: 単位 2 種で技能は完成し、3 種目は桁の事務量で認知を壊すだけによる。換算ドリルと揃え計算の答えは 6 桁以内 (原理 Lv の関係定数 1m³ = 1000000cm³ は例外)。重さ (kg/t、mg/g) は易しいため v1 方針どおり範囲外。
- 揃え計算 (Lv9) の診断定番誤答: 単位を無視して生の数字を計算する (1.2 − 400 型)。判定語彙は「単位がちがう」。
- わざ: 「面積の階段は ×100、体積は ×1000!」「長さ ×100 なら、面積は 2 回、体積は 3 回掛ける!」「単位がちがったら、まず揃える!」「一気に跳ばず、知っている橋を渡る!」
- 形式: normal + diagnosis + ordering (経路 4 手、基準例は `docs/komorebi_item_examples.md` U2)。回答は数値入力と単位選択の分離を維持し、「数値は合うが単位が違う」を正答にしない。

### 3.9 kom_frac_flow (分数計算の解法手順、2026-08-12 追加)

潰す弱点 (実測): 分数の乗除で途中約分をせず、大きい数を作ってから約分する。帯分数の加減で仮分数経由の遠回りをする。本編 K10CATS の frac (計算演習 10 段階: 同分母加減から帯分数入り四則まで) と出題範囲は重なるが、本編が「答えを出す」練習であるのに対し、本カテゴリは過程の外化と計算量を減らすわざを扱う分業とする。

主砲わざ: 「かける前に約分!」(途中約分)、「整数は整数、分数は分数で!」(帯分数の分けて計算)、「ひっくり返してから約分!」(除法)。検算わざ: 「答えが約分できたら まだ終わってない」。

| Lv | 内容 |
|---|---|
| 1 | 約分の完成判定と一発約分 (12/18 → 2/3。「まだ約分できる?」) |
| 2 | 通分の相手探し (最小公倍数の選択。1/6 と 1/8 → 24。48 は遠回り) |
| 3 | 異分母加減のフル手順 (整列: 通分 → 分子計算 → 約分チェック) |
| 4 | 帯分数の加算: 分けて計算 (2 1/4 + 3 2/5 = 5 + 13/20) |
| 5 | 帯分数の減算: 繰り下がり (5 1/4 − 2 3/4 = 4 5/4 − 2 3/4 = 2 1/2) |
| 6 | 乗法の途中約分 (4/9 × 3/8 = 1/3 × 1/2 = 1/6) |
| 7 | 除法: ひっくり返してから約分 (÷のまま約分する事故を診断で扱う) |
| 8 | 帯分数の乗除 (仮分数 + 途中約分の合成。2 2/5 × 1 1/4 = 12/5 × 5/4 = 3) |
| 9 | 三口・加減乗除の混合 (どの技を使うかの判断が実地で発生する) |
| 10 | 総合 |

- 戦略の学習ドライバは 3 つ: 楽な道の優位が体感できる数値設計 (約分が効いて一瞬で終わる組を優先)、正解者にも別の道を見せる解説カード、真の誤りのみを採点する診断。遠回りの正解 (仮分数経由等) は「正しい (べつのとき方)」と判定し、解説カードで楽な道をサジェストする。
- 形式: normal + 整列 (Lv3 から 5 の加減フロー。乗除の途中約分は約分順序が交換可能で一本鎖の一意性に載らないため整列にしない) + 診断。
- 回答は既存の frac kind (分子・分母入力) を流用する。帯分数の整数部入力の対応可否は実装時に確認する。
- 前提: 本編 frac の異分母標準 (Lv5 相当) までを履修済みの想定。

### 3.10 kom_kuku_run (れんぞく九九、2026-08-12 新設)

潰す弱点 (実測): 累加依存。暗算が速い子は 8×7 を 8 の 7 回加算で毎回解けてしまい、正答率が高いまま想起練習が発生せず、九九が自動化しない。累加でも正答するため正誤データでは検出できず、応答レイテンシを無音で計測して検出する。

- 九九 SRS: 遅い正答 (計算の疑い) の fact は短期間に繰り返し再出題し (「さっきやったやつだ」と認識させてそのまま覚えさせる)、句の足場を付ける。速い正答が続いた fact は間隔を広げる。漢字 SRS と同じ発想。
- 短ループ想起: 8×7 = 56 を句と一緒に見せ、数問はさんで 8×7 を出題する。直前に見たものの想起が累加より安い場を作り、「まず想起 → だめなら計算」の順序を成立させる。
- 形式は「しつこい九九ドリル」(教材おきば、2026-08-12 参照) の 5 形式を翻訳: だんラン (順つなぎ。おとりは ±1 と隣の段の値)、まきもの穴埋め (前後の積が見える足場)、たりないさがし (段の完全性)、まちがいさがし、フラッシュ。ブロックかぞえと文章問題はカバーしない (意味理解は本編、立式は kom_equation_select の領分)。
- 時間の可視要素は置かない。カウントダウンも速度ボーナス演出も不採用 (2026-08-12 決定: 罰型の時間圧は過負荷リスク、装飾ボーナスは追加しない)。時間はレイテンシの内部利用のみ。

回答は数値タップ。ゲージはだんラン 1 本 = 1 正答。

## 5. わざフィールド (解答フローの一言)

今回の小道改修の主眼は 10 歳コースの解答フローへの理解の整備である (2026-08-12)。その実装単位として、生成器の意味モデルに waza フィールドを持たせる。わざは「この問題での頭の動かし方」を名前付きの一言 + 手順にしたもの。生成器は数値を自分で組み立てるため、どのわざが効くかを決定的に付与できる。

| 種別 | 中身 | 例 |
|---|---|---|
| 工夫 | 計算を楽にする変形 | ×49 は ×50 から 1 個引く |
| 方向 | どの演算へ向かうかの合図 (トリガー語と対にする) | もとにする量を聞かれたら わり算で戻す |
| 立式 | 式を立てるまでの手順の言語化 | 聞かれているのは何 → 分かっているのは何 → 型に当てはめる |
| 検算 | 答えの妥当性チェック | 全体が部分より小さくなったら おかしい |

注入点は 2 か所で、ゲージ規則と干渉しない。

1. 出題前の足場 (scaffold)。問題文の一部でありヒント扱いにしない (正答は通常どおり加算)。
2. 回答後の解説カード。正誤に関わらず表示し、筆算で正解した子にも楽な道を毎回見せる (正解者への技サジェスト)。primary 1 本 + 「別の道」1 行の 2 段構成とし、同じ答えへ 2 つの道が通じることを見せて数感覚と検算習慣を育てる。

回答前のひらめきボタンは v1 では作らない (design 5.3 のヒント無加算規則との干渉を避ける)。わざの語彙はカテゴリごとに教材設計文書で定義する。文言は k10 カテゴリでは漢字トーン、k5 カテゴリではひらがなトーン (「さきに まとめて ×10!」)。

## 6. 連鎖セット (認識から産出への橋)

立式・整列・診断はいずれも「選ぶ・並べる・見抜く」認識課題であり、白紙の問題から自分で式を立てる産出とは距離がある。このギャップを塞ぐため、5 問セット内の配置規則として連鎖を標準にする (2026-08-12 決定):

- 立式 → 同じ意味モデルの normal を直後に置く (選んだ式を自分で計算して答えまで到達する)
- 診断 → 同型の normal を直後に置く (誤り型を見抜いた直後に「正しくやってみる」)

生成器は意味モデルを共有しているため、新しい問題形式や 2 段階入力 UI (ratio curriculum 9 章で不採用) を作らずに、配置規則だけで認識と産出が毎セット内で接続される。転移の最終検証はゲーム内では行わず、本編の対応カテゴリ (frac、hiritsu 等) の成績変化を保護者が観察する外部検証に委ねる。
