## 1. 記載原則

1. すべてのカテゴリは「潰す弱点」を 1 行で明文化する。弱点に紐づかないカテゴリは追加しない。
2. Lv1 から 10 は難易度が単調に上がること。軸は量の増加ではなく操作の質 (想起、構造、工夫、統合、逆算、派生) で設計する。
3. 形式 (normal / formulation / ordering / diagnosis / voice) の適合をカテゴリごとに明示する。
4. 本編カテゴリ (K5CATS / K10CATS / K5DEV 30 / K10DEV 22) との重複照合を採用条件とする。

### 3.4 kom_pi314 (3.14 の段、2026-08-12 v2 確定版)

v1 案の Lv4 から 6 (3.14×11 から 20 の直接暗記) を棄却し、工夫計算テクニックの梯子として再設計した。確実に覚える対象は ×1 から 9 の 9 個のみ。平方数の積は暗記を強制せず、わざで素早く自作できる馴染みを目標とする (頻出の ×16 と ×25 は反復で自然に定着する)。構造は螺旋: 技 (Lv5 まとめ) を弾が少ないうちに導入して「まとめると覚えている範囲に収まる」即効を体感させ、弾 (Lv6 平方数) を増やし、技×弾 (Lv7) で往復する。

| Lv | 内容 | 操作の質 |
|---|---|---|
| 1 | 3.14×1 から 5 の想起 | 想起 |
| 2 | 3.14×6 から 9 の想起 (繰り上がり多発帯) | 想起 |
| 3 | ×1 から 9 の完全混合 | 想起の自由度 |
| 4 | 位取り: ×10、×20 から 90、×100 (31.4×n との等価を明示) | 構造 |
| 5 | まとめ入門: 3.14×a ± 3.14×b の係数を先にまとめ、×2 から 9 か ×10 に収める。まとめない場合の苦痛差が大きい数値組を優先する | 技の導入 |
| 6 | 平方数の積への馴染み: ×16、×25、×36、×49、×64、×81 を Lv4 と 5 の技で自作する | 弾の拡張 |
| 7 | まとめ発展: 差 (輪の面積型)、3 項、÷2 の係数化、まとめ先が平方数になる組 | 技×弾 |
| 8 | 逆引き: 3.14×□ = 積 (円周・面積からの逆算に対応) | 逆算 |
| 9 | 分配・展開: ×13 = ×10 + ×3 (まとめの逆向き)。31.4×n、0.314×n の小数位取り | 派生 |
| 10 | 全形式混合 | 統合 |

平方数 6 個の primary わざ (選定基準: 小数の位ずれ加算を避ける。偶数 = 倍々、奇数 = きりのいい数から調整):

| n | primary | 別の道 |
|---|---|---|
| ×16 | ×8 の 2 倍 (25.12 → 50.24) | ×10 + ×6 |
| ×36 | ×18 の 2 倍 (×9 → 56.52 → 113.04) | ×30 + ×6 |
| ×64 | ×32 の 2 倍 (×16 → 100.48 → 200.96) | ×60 + ×4 |
| ×25 | 314 の半分の半分 (157 → 78.5) | ×20 + ×5 |
| ×49 | ×50 − ×1 (157 − 3.14 = 153.86) | なし |
| ×81 | ×80 + ×1 (251.2 + 3.14 = 254.34) | なし |

偶数組は ×8 → 16 → 32 → 64 と ×9 → 18 → 36 の倍々家系、奇数組は 314 と 157 のランドマークからの調整で、覚える体系は 2 本にまとまる。

- 出題数値の分布ルール: 円の問題で現れる分布 (直径 1 から 20 相当、平方数、半円係数) に寄せる。円周・面積の文章題そのものは入れない (v1 方針維持)。
- 形式: normal のみ。診断・立式・音声は不適用 (design 7.2 章)。わざ (5 章) は足場と解説カードにのみ現れる。
- 時間要素は使用しない。

### 3.9 kom_frac_flow (分数計算の解法手順、2026-08-12 追加)

潰す弱点 (実測): 分数の乗除で途中約分をせず、大きい数を作ってから約分する。帯分数の加減で仮分数経由の遠回りをする。本編 K10CATS の frac (計算演習 10 段階: 同分母加減から帯分数入り四則まで) と出題範囲は重なるが、本編が「答えを出す」練習であるのに対し、本カテゴリは過程の外化と計算量を減らすわざを扱う分業とする。

主砲わざ: 「かける前に約分!」(途中約分)、「整数は整数、分数は分数で!」(帯分数の分けて計算)、「ひっくり返してから約分!」(除法)。検算わざ: 「答えが約分できたら まだ終わってない」。

| Lv | 内容 |
|---|---|
| 1 | 約分の完成判定と一発約分 (12/18 → 2/3。「まだ約分できる?」) |
| 2 | 通分の相手探し (最小公倍数の選択。1/6 と 1/8 → 24。48 は遠回り) |
| 3 | 異分母加減のフル手順 (整列: 通分 → 分子計算 → 約分チェック) |
| 4 | 帯分数の加算: 分けて計算 (2 1/4 + 3 2/5 = 5 + 13/20) |
| 5 | 帯分数の減算: 繰り下がり (5 1/4 − 2 3/4 = 4 5/4 − 2 3/4 = 2 1/2) |
| 6 | 乗法の途中約分 (4/9 × 3/8 = 1/3 × 1/2 = 1/6) |
| 7 | 除法: ひっくり返してから約分 (÷のまま約分する事故を診断で扱う) |
| 8 | 帯分数の乗除 (仮分数 + 途中約分の合成。2 2/5 × 1 1/4 = 12/5 × 5/4 = 3) |
| 9 | 三口・加減乗除の混合 (どの技を使うかの判断が実地で発生する) |
| 10 | 総合 |

- 戦略の学習ドライバは 3 つ: 楽な道の優位が体感できる数値設計 (約分が効いて一瞬で終わる組を優先)、正解者にも別の道を見せる解説カード、真の誤りのみを採点する診断。遠回りの正解 (仮分数経由等) は「正しい (べつのとき方)」と判定し、解説カードで楽な道をサジェストする。
- 形式: normal + 整列 (Lv3 から 5 の加減フロー。乗除の途中約分は約分順序が交換可能で一本鎖の一意性に載らないため整列にしない) + 診断。
- 回答は既存の frac kind (分子・分母入力) を流用する。帯分数の整数部入力の対応可否は実装時に確認する。
- 前提: 本編 frac の異分母標準 (Lv5 相当) までを履修済みの想定。

## 4. 検証記録 (2026-08-12)

1. kom_pi314 の v1 案 (×11 から 20 の直接暗記) を棄却した。理由: 小 6 の円面積で実際に使う平方数積を素通りし、任意の n に般化せず、難易度軸が量の増加にとどまるため。確定版は暗記 15 項目で v1 案の 20 項目より軽く、命中率は高い。
2. 本編カテゴリとの重複照合済み。単位換算は本編が低学年単位 (nagasa / kasa / omosa) のみで高学年換算 (a / ha / km²、mL / L / m³) は空白。円周率ドリルも本編に存在しない。
3. kom_ratio_forms は kom_ratio Lv1 (表現変換) と入口が重複するため予備在庫化した。
4. kom_equation_select は立式形式と役割が重なるが、k5 側の受け皿として独立維持を決定した。
5. Lv 勾配の再検証で kom_unit_convert Lv5 の小数複名数の跳びを修正した (3.5 章)。他カテゴリの勾配に欠陥は見つからなかった。
6. kom_pi314 は 2026-08-12 のチャットレビューで工夫計算の梯子として v2 再設計した。まとめ技を Lv5 へ繰り上げ (弾が少ないうちに技を入れて即効を体感させる)、平方数は暗記強制から馴染み目標へ変更、分配は Lv9 へ降格、わざフィールド (5 章) を新設。
7. kom_frac_flow を追加した (2026-08-12)。単純な分数計算演習は本編 frac と重複するため作らず、過程とわざに特化した分業とした。「どの道が楽かを選ぶ」経路選択の採点形式は検討の末に不採用: 遠回りの正解を不正解扱いすることになり「正しさは罰しない」方針と矛盾する、まともな選択肢が実質二択に崩れる、戦略の知識と実行は別物で乗り換えは体感の反復から起きる、の 3 点による。戦略は数値設計・わざカード・診断の 3 ドライバで学習させる。equation_select は第 4 陣へ繰り下げ。

## 5. わざフィールド (解答フローの一言)

今回の小道改修の主眼は 10 歳コースの解答フローへの理解の整備である (2026-08-12)。その実装単位として、生成器の意味モデルに waza フィールドを持たせる。わざは「この問題での頭の動かし方」を名前付きの一言 + 手順にしたもの。生成器は数値を自分で組み立てるため、どのわざが効くかを決定的に付与できる。

| 種別 | 中身 | 例 |
|---|---|---|
| 工夫 | 計算を楽にする変形 | ×49 は ×50 から 1 個引く |
| 方向 | どの演算へ向かうかの合図 (トリガー語と対にする) | もとにする量を聞かれたら わり算で戻す |
| 立式 | 式を立てるまでの手順の言語化 | 聞かれているのは何 → 分かっているのは何 → 型に当てはめる |
| 検算 | 答えの妥当性チェック | 全体が部分より小さくなったら おかしい |

注入点は 2 か所で、ゲージ規則と干渉しない。

1. 出題前の足場 (scaffold)。問題文の一部でありヒント扱いにしない (正答は通常どおり加算)。
2. 回答後の解説カード。正誤に関わらず表示し、筆算で正解した子にも楽な道を毎回見せる (正解者への技サジェスト)。primary 1 本 + 「別の道」1 行の 2 段構成とし、同じ答えへ 2 つの道が通じることを見せて数感覚と検算習慣を育てる。

回答前のひらめきボタンは v1 では作らない (design 5.3 のヒント無加算規則との干渉を避ける)。わざの語彙はカテゴリごとに教材設計文書で定義する。文言は k10 カテゴリでは漢字トーン。
