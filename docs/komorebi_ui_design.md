- 親文書: `docs/komorebi_design.md`、`docs/komorebi_categories.md`、`docs/komorebi_release_linkage.md`
- 実装計画: `.claude_plan/komorebi_phase3_prototype.md`
- 絵柄の決定に使ったモック: https://claude.ai/code/artifact/32eb408a-af3a-4f29-9c0f-bfd5155aebf1 (案 1 厚塗り / 案 2 探検ノートの比較。案 1 採用)

## 1. 入口はホームマップではなくけいさんの中

小道のカテゴリは k5 (九九 5 本、式選択、ぜんぶさがし) も k10 (割合、3.14 の段、単位換算、分数フロー) も**すべて算数**であり、漢字も英単語も 1 つもない。したがって小道は独立した島ではなく、けいさんから分岐した脇道である。名前 (小道) と構造が一致する。

- 入口: けいさん内のエントランスボタン。けいさんは K5CATS と K10CATS の両コースを持つ唯一のゲームなので、入口 1 つで 5 歳と 10 歳の双方に届く。
- ホームマップ (`assets/home_map_*.webp` + % 座標のホットスポット) には追加しない。現行マップは縦 0 から 92% がほぼ埋まっており、段を足すには base island の描き足しが要る。入口をけいさんに置けば絵の追加なしで成立する。
- 解禁: 初回リリース時に全プロフィールで無条件に開ける。弱点補強エリアなので条件を課す理由がない。
- 発見演出: 解禁後の初回けいさん起動時に 1 度だけ。既存の かせきのたに 解禁演出 (`index.html` 785 から 811 行、派手な 1 度きり) と同じパターンを流用する。文面の方向:

```
✨ こもれびの こみちを 見つけた！
どうやら 外国に つながっているようだ…？！
```

- 発見演出のあと入口が埋もれるのが唯一のリスクなので、ボタンはカテゴリ一覧の先頭に帯として置き、常時目に入る位置を確保する。

## 2. 御神木パネルの小道カウント

ホームの御神木パネル (`index.html` 587 行) に累計カウント行を置く。絵ではなく HTML 行なので追加コストはない。

- 表示: `🌿 こもれび 145/300` (全 volume 合計)。ホームで蓄積が見える。
- その行をタップで小道へ移動できる。地図に絵を足さずにショートカットが増える。
- 遠征ページ側は volume 別 (`34/100`)。累計と手の届く目標を別の場所に置き分ける。
- 解禁前は非表示。

## 3. 小道トップ = 世界の地図

小道を開くと表題 (木漏れ日の小道。10 歳は漢字、5 歳は furi5 のふりがな) と世界地図が出る。地図は装飾ではなく地域の選択ハブであり、過去地域の常時開放 (design 5.5) をナビゲーションとして自然に表現する。

**絵柄: 案 1 厚塗り寄り** (2026-08-13 決定)。深い海のグラデーション、金色の光、宝石のようなピン。御神木マップと同じ世界の続きに見え、ホームから小道へ移動しても手ざわりが変わらない。

**地図の作り方**

- 投影法は Equal Earth (等積図法)。アフリカとマダガスカルが実際の大きさで出る。メルカトルは使わない (グリーンランドが肥大しアフリカが縮む。地理を覚えるという狙いに反する)。
- 国境は描かない。大陸の輪郭のみ。政治的な面倒がなく、子どもには読みやすい。
- 素材は `tools/komorebi/build_world_map.py` が生成する `komorebi/assets/world_paths.json` (Natural Earth 由来のパブリックドメイン輪郭)。画像ではなくパスなので拡大しても粗くならず、陸地は 1 本のパスを地図全体で共有する。

**地域の形をどこで見せるか (2026-08-13 修正)**

当初は世界地図の上で地域の輪郭を光らせて形を覚えさせる設計だったが、実装して見ると成立しなかった。等積図法の世界地図では地域が小さすぎる (投影後の幅はオーストラリア 137 に対しコスタリカ 11、マダガスカル 33、ボルネオ 42) ため、光らせても形として読めない。

役割を分ける。

- 世界地図: **位置**を示す。ピンが主たる標識で、地域ハイライトは大きな地域での補助的な強調に留める。
- 下のパネル: **形**を見せる。選択中の地域の輪郭を単独の viewBox で 88 から 112px に拡大して描く。ここで「マダガスカルはこういう形の島」が読める。

拡大表示には地域ごとの外接矩形が要るので、`build_world_map.py` が `regionBoxes` を payload に出力する。輪郭データ自体は地図と共通で、`tools/komorebi/regions.json` の国コードまたは WKT ポリゴン由来。**虫を集めた範囲と地図と形の表示が同一データ**であることは変わらない。

**ピン**

- 現在の地域: ★ + ゆっくり脈動するハロー
- 過去の地域: 🦋 + 進捗リング (円弧で `45/88` を表現)。常時開放でタップして入れる
- 完成した地域: ✓ + 緑のリング
- 未解放地域: ピンなし、輪郭のみ。この余白が次の更新への期待になる
- ピンは地理的実寸と無関係の固定サイズ (タップ 44px 以上)。マダガスカルは実寸だと数ピクセルなので、位置だけ正確に、大きさは操作性優先

**下端の一言コメント**

ピンを選ぶと画面下端に地域の説明が 2 から 3 行出る。深追いはしない。

```
マダガスカル　アフリカの東にうかぶ大きな島。日本の 1.6 倍。ここにしかいない虫がとても多い。
```

**ふりがな (k5 モード必須)**

コメントと地域名は漢字で書き、`p.type === "k5"` のときに既存の `furi5()` (`keisan/app.js` 5799 行以降、`FURI5_PAIRS` 辞書、ruby タグ生成、処理済み領域の保護つき) を通してふりがなを振る。地理語彙 (島、大陸、南半球、雨林、広さ 等) を `FURI5_PAIRS` に追加する。テキストを 2 種類持たず 1 つの原文から出し分ける。

## 4. 地域の小道ページ

ピンをタップすると開く。ギミックは要らない。

- その地域の小道 (= その volume の offers。design 3.2 と 316 行) をカテゴリのボタンとして数個
- その volume の図鑑への入口
- 進捗 (`34/100`)
- 選んだら問題に入る。それだけ

## 5. 小道図鑑は本編から独立

小道の図鑑は小道の中に持ち、カウントも別枠にする (design 固定仕様 1、決定 9)。k5 と k10 でコレクションは共有する。

**実装上の地雷 (必ず対処する)**

`shared/reward.js` の 30 行は `BUGS.forEach` で全種を無条件に POOLS へ入れ (除外は masterOnly / bossOnly / SS のみ)、44 行以降の ZUKAN_DENOM も同様に全種を走査する。小道の種を `bugs.js` に足すとそのまま:

- 本編の抽選プールに混入し、けいさんで小道の虫が捕れてしまう
- 本編図鑑の分母が膨らみ、477 / 402 / 473 が壊れる

対策として entry に `areaOnly: "komorebi"` フラグを持たせ、POOLS 構築と ZUKAN_DENOM 構築の 2 か所で除外する。これで `bugs.js` の描画資産 (order/family からの archetype 自動細分化、colors) を全部再利用しつつ隔離できる。回帰テストで固定する。

**見た目の区別**: けいさんの中に「けいさん図鑑」と「小道図鑑」が並ぶので、枠色とヘッダで別物と分かるようにする。

## 6. トロフィーの置き場所

カテゴリを Lv10 クリア (安定判定 20 問 85%、到達ではない。design 6.6) すると金色のトロフィー虫を得る。

- 飾る場所: 小道トップの下端に入口 (獲得数つき) を置き、専用のトロフィーページへ送る (2026-08-13 決定)。横一列の棚は採らない。トロフィーは Lv10 クリアが条件で最初の数週間はゼロのため、空の棚がトップに常時居座るのは虚しく場所も食う。
- ページには**未獲得の枠も並べる**。獲得済みは金の虫と獲得日、未獲得は錠前と条件 (そのカテゴリを Lv10 クリア) を示す。これで空のページが「何もない部屋」ではなく目標ボードになり、獲得条件が Lv10 到達ではなくクリアであることが初めて子どもに見える形になる。
- 金色化に素材は要らない。`Q4BRender.species()` は `sp.colors` を読むだけなので、金のパレットに差し替えた種のコピーを渡せば金の虫が描ける (`Q4BReward.svg(Object.assign({}, sp, {colors:["#F0C24A","#8A6410"]}))`)。額縁は CSS の装飾で足りる。
- 代表虫の決め方は design 6.7 のまま (その cat の最終 Lv 帯を投入した volume の看板。k5 cat は volume 内の別 SR を trophy manifest で個別指定)。
- 看板が写真つきの種になっても、トロフィーはパラメトリック SVG 側を金色化して使う (写真は金にできない)。

## 7. 呼称

画面では「遠征」を前面に出さない。木漏れ日の小道は静かな脇道であり、遠征という語感と合わない。遠征 I / II / III は同一地域への再訪を区別する volume の内部番号 (design 3.2) として管理側でのみ使う。画面の呼称は次で統一する。

| 対象 | 画面の呼称 |
|---|---|
| エリア全体 | 木漏れ日の小道 |
| トップの地図 | 世界の地図 |
| 地域のページ | 「マダガスカルの小道」 |
| 地域内のカテゴリ | その地域の小道 |
