## 4. 数の大小の除外は正当か

### 4.1 判定

正当とは判定しない。両辺については、技能ではなく生成器の副産物である。2 数については、近道の一種である。

### 4.2 根拠 (両辺)

1. 算数として大小が決まっているのは 3 型だけである。`a-□=b+c` (T_SB) では a = □ + b + c なので a > b + c。`a+□=b+c` と `□+a=b+c` (T_AB、T_AF) では b + c = □ + a なので b + c > a。どれも式の形から必ずそうなる。
2. `□-a=b+c` (T_SF) では □ = a + b + c で、a と b + c はどちらが大きくてもよい。`□-30=5+3` (□ = 38) は 2.3 章の規約のどれにも反しない正しい問題である。3.10 章の「他の型は b + c > a」だけが、これを出さないようにしている。
3. op と mag は、この制限があるときだけ 1.000 になる。T_SF に a > b + c の問題を半分混ぜた版 (後述 5 章の sfmix) では 0.85 から 0.88 に下がる。この手続きが外れる問題は、正しい技能 (op と pos) なら全部解ける。外れる問題が存在するのに、それを出さないことで当たっている手続きは、技能ではなく近道である。
4. 3.10 章は「a と b + c のどちらが大きいかは、□ が ぜんぶか片方かの読み取りそのもの (`WZ_hitotsu`)」とする。T_SB と T_AB、T_AF ではそう言える (見えている数のどれが ぜんぶかが、大小と一致する)。しかし T_SF では ぜんぶは □ そのもので、見えていない。「見えている中でいちばん大きい量が ぜんぶ」と読む子は、T_SF の a > b + c の問題で `a-b-c` を作って外す。これは 1 章が潰そうとしている誤り (= のむこうを答えの合図と読む構え) の一形態である。v0.3 はこの誤りを試す問題を出さないので、誤りを持った子が Lv5 から Lv9 を 1.000 で通る。
5. 「a はどの型でもいちばん大きい」(a > b かつ a > c) の規則そのものは、大小だけで正答を組める手がかりではない。a と b の大小は型によらず一定で、型を語らない (C7 の意図どおり)。手がかりになるのは a と b + c の比較で、これは 1 と 2 のとおり型で決まる。ただし a が最大であることで、a の絶対的な大きさ (amax) と 3 数の和 (size) が a と b + c の比較の代わりになる。op と amax は、T_SF の上限を全型にそろえた版でも 0.82 から 0.84 で残る。

### 4.3 根拠 (2 数)

`□+x=y` では必ず □ の側が小さく、`y-□=x` では必ず □ の側が大きい。`□-a=d` だけが半々である (3.1 章)。op と mag、pos と mag は、それぞれ T_SF の半分を必ず外す (Lv2 で 0.829 と 0.838)。技能 (op と pos) なら外さない問題を外すので、これも近道である。ただし前回の監査 5 章の 3 のとおり、2 数だけの Lv では、どう比率を組んでもこの 2 つの手続きのうち大きいほうを 0.75 未満にできない。Lv2 の例外を「大小の組も含めて 0.70 未満を求めない」と明記するのが正直な扱いである。

### 4.4 除外を外したときに何が起きるか

両辺で T_SF の a > b + c の割合を p とすると、op と mag の誤りは min(s, f × p)、pos と mag の誤りは min(α_F, f × (1 - p)) で、pos の後ろ (T_AB と T_SB) は mag で必ず分かれる。2 つをどちらも 0.75 未満にするには、s ≥ 0.25、α_F ≥ 0.25、f ≥ 0.5 が要り、合計が 1 を超える。段 A の「ぎゃくの演算」(1 - s) を 0.60 未満にする条件 (s > 0.40) とも両立しない。したがって、大小の組を敵に数えるなら、Lv5 から Lv9 は v0.3 の形式のままでは段 B を満たせない。除外を残すか、Lv の構成を変えるかは発案者の判断になる。本監査が求めるのは、除外を残す場合でも次の 2 点である。

1. 除外の根拠を「技能そのもの」と書かない。「T_SF の a > b + c を出さないことで成り立つ近道を、0.75 の判定から外す」と、副産物であることを書く。
2. T_SF の a > b + c の問題を一定の割合で出し、大小で決める子がそこで外れるようにする (観測できるようにする)。そのとき op と mag は 0.85 から 0.88、除外の外の amax の組は 0.71 から 0.78 になる (5 章)。

### 6.2 新しく見つけたもの

- N1. 3.10 章は「v0.3 では大小で残る差は a と b + c のどちらが大きいかだけ」と書くが、同じ 3.10 章が T_SF にだけ a + b + c ≤ 100 を課しているので、数の絶対的な大きさが型で大きく違う (2 章の size)。検証 13 もこの組を見ない。
- N2. 11.3 章の参考値「op と大小 0.84 から 0.92」と「大小 (単独) 0.636」は、3.10 章の条件と合わない。3.10 章の条件だけから、両辺の op と (a と b + c の比較) は答えを 1 つに決めるので 1.000、大小を単独で使えば s + max(α, f) = 0.72 になる。sim の大小の特徴が、3.10 章が述べる比較より粗いと考えられる。11.5 章の 3 と 12 章の 4 は、この低く出た参考値の上に「除外の範囲」を論じている。
- N3. 4.4 章は「T_AB が 3% と少ないのは、T_AB が段 B の pos の値をそのまま押し上げるため」と書くが、同じ節の式 max(α_F, f) + max(α_B, s) では、α_B は s (0.43) を超えない限り pos の値を上げない。T_AB の比率が効くのは段 A の「□ が まえなら たす」(f + α_B) で、本文の理由と式が対応しない。
- N4. 3.6 章の P1 は「a は、その型が許せば同じ数、許さなければ同じ b と c で引き直す」として、どの型も取れる前提で書いているが、b と c によっては取れない型がある (たとえば b + c > 66 では T_SF が、b + c > 97 では T_SB が取れない)。検証 10 は「a の制約で取れない型を除いた比率」と書き、3.6 章と前提が食い違う。取れないときにどうするかが規則に無い (本監査の生成器は 1 問目から引き直した)。
- N5. 付録 A は独立抽選なので、各 Lv の新しい操作を含まないセットがある。A.4 (Lv4) は 2 数の逆向きを 1 問も含まず、A.5 (Lv5) は T_SB と T_SF だけで T_AF と T_AB を含まない。規則には反しないが、5.1 章の「Lv4 で新しく入る操作」が付録 A では実在を示せていない。
- N6. 冒頭と 9.1 章は sim を「独立監査の生成器を改修したもの」とし、C8 は「再監査と実装の回帰テストには監査側の生成器と敵を使う」とする。repo の sim は設計側が改修したもので、本監査の生成器とは別物である (本監査の値と 0.01 から 0.09 ずれる。N2 の大小で最大)。検証 22 が回帰に使うのはその sim の敵なので、C8 の「監査側の生成器」には当たらない。
