## 1. kom_ratio (割合と比、k10)

| Lv | 形式 | 問題 | 正答 |
|---|---|---|---|
| 1 | normal | 0.08 を百分率で表すと何%ですか | 8 |
| 2 | 立式 | 50人のうち 8人が休みました。休んだ人は全体の何%ですか。しき: 8÷50 / 50÷8 / 8×50 / 50−8 | 8÷50 (16%) |
| 3 | 立式 | 600円の 40% は何円ですか。しき: 600×0.4 / 600÷0.4 / 600×40 / 600÷40 | 600×0.4 (240円) |
| 4 | 診断 | 18人が全体の 45% にあたります。全体は何人ですか。答案「しき 18×0.45=8.1 こたえ 8.1人」 | かけ算とわり算のえらび方がちがう (正: 18÷0.45=40人) |
| 5 | 整列 | 800円の品物を 3割引きで買います。はらうお金は? 部品: [3割 → 0.3] [800×0.3=240] [800−240=560] | この順 (560円) |
| 6 | 整列 | 1500円の品物を 40%引きで買い、さらに 100円引きクーポンをつかいました。はらったお金は? 部品: [40%引きは ×0.6] [1500×0.6=900] [900−100=800] | この順 (800円) |
| 7 | 診断 | 1200円を兄と弟で 3:2 に分けます。兄は何円ですか。答案「しき 1200×3/2=1800 こたえ 1800円」 | もとにする量とくらべる量が逆 (全体は 3+2=5。正: 1200×3/5=720円) |
| 8 | 立式 | ある本の 2/5 を読んだら 36ページでした。この本は全部で何ページですか。しき: 36÷2/5 / 36×2/5 / 36÷5 / 2/5÷36 | 36÷2/5 (90ページ) |
| 9 | 診断 | 原価 600円に 3割の利益を見込んで定価をつけ、定価の 2割引きで売りました。売価は何円ですか。答案 A「600×1.3=780、780×0.8=624」/ B「600×1.04=624」/ C「600×1.3=780、780×0.2=156」/ D「600×1.1=660」 | A 正しい、B 正しい (べつのとき方)、C 聞かれたものと別のものを答えている、D 順番や組み立てがちがう |
| 10 | normal (混合) | クラス 25人の 60% が本を借りました。借りた人は何人ですか | 15人 |

- Lv8 の誤答注意: `36÷2×5` と `36×5/2` は正解と同値 (逆数の掛け算) なので誤答候補に置けない。validator の非等価検査が弾く実例。
- Lv9 の D (3割増 − 2割引 = 1割増とまとめる誤り) は正答 624 と 36 円しか差がなく、検算では気づきにくい型。

## 5. kom_unit_convert (単位換算、k10)

| Lv | 問題 | 正答 |

| 2 | 1m³ = □L (体積の階段の想起) | 1000 |

| 4 | 5a = □m² (面積の換算) | 500 |

## 6. kom_equation_select (文章題の式選択、k5)

| Lv | 問題 | 正答 (誤答候補) |
|---|---|---|
| 1 | あかい 花が 8本、しろい 花が 7本 さいています。あわせて 何本? | 8+7 (8−7 / 8×7 / 7−8) |
| 2 | バスに 12人 のっています。5人 おりました。のこりは 何人? | 12−5 (12+5 / 5−12 / 12×5) |
| 3 | りんごが 14こ、みかんが 9こ あります。りんごは みかんより 何こ 多い? | 14−9 (14+9 / 9−14 / 14×9) |
| 4 | 1ふくろに 6こ入りの あめが 4ふくろ あります。ぜんぶで 何こ? | 6×4 (6+4 / 6−4 / 6+6+6) |
| 5 | クッキーが 20まい あります。4人で 同じかずずつ 分けると 1人 何まい? | 20÷4 (20×4 / 20−4 / 4÷20) |
| 6 | 30この いちごを 1さらに 5こずつ のせます。おさらは 何まい いる? | 30÷5 (30×5 / 30−5 / 5÷30) |
| 7 | シールを 何まいか もっていました。おねえさんに 6まい もらったので、いま 15まい です。はじめは 何まい? | 15−6 (15+6 / 6−15 / 15×6) |
| 8 | 1はこに 同じかずずつ入った クッキーが 6はこで 42まい あります。1はこは 何まい? | 42÷6 (42×6 / 42−6 / 6÷42) |
| 9 | えんぴつが 12本 あります。9さいの ゆいさんが 4本 つかいました。のこりは 何本? (不要情報あり) | 12−4 (12−9 / 12+4 / 9−4) |
| 10 | 1こ 60円の パンを 2こ 買って、200円 はらいました。おつりは 何円? (式を順に 2つ) | さいしょ 60×2=120、つぎ 200−120=80 |

- Lv7 の誤答 15+6 は「もらった = たし算」の表面語反応。Lv9 の誤答 12−9 は不要情報 (年れい) への数値反応。どちらも選ばれた瞬間に弱点が特定できる。
- Lv1 の誤答 7−8 は引けないことに自分で気づかせる意図の順序反転肢。採否は静的レビューで再確認。

## 9. 実物イメージ: kom_ratio Lv6 の 5 問セット mock

形式配合 (curriculum 4 章: normal 1 / ordering 2 / diagnosis 2) に従った 1 セットの通し例。

1. [normal] 400人の 30% の、そのまた 50% は何人ですか。 (60人)
2. [整列] 2000円の品物を 20%引きしたあと、さらに 10%引きしました。何円になりましたか。部品: [20%引きは ×0.8] [2000×0.8=1600] [1600×0.9=1440]
3. [診断] 上と同じ問題のゆうまさんの答案「20+10=30、2000×0.7=1400」→ 順番や組み立てがちがう
4. [整列] 1500円の品物を 40%引きで買い、さらに 100円引きクーポンをつかいました。部品: [40%引きは ×0.6] [1500×0.6=900] [900−100=800]
5. [診断] 300人の 40% が水泳をならっていて、そのうち 25% が英語もならっています。両方ならっているのは何人ですか。答案「しき 300×0.25=75 こたえ 75人」→ もとにする量とくらべる量が逆 (「そのうち」の基準は 120人。正: 120×0.25=30人)

- 2 と 3 のように同一場面を整列と診断で使い回すのは初回セットの導入時のみ許可 (同じ思考を作る側と検査する側の両面から見る)。通常セットでは場面を変える。
