# 機械化可能性監査 (2026-08-14)

- 対象: 小道新カリキュラム draft 5 本 (kisokusei / hayasa / ratio_forms / johou_seiri / diagram_model、いずれも v0.1)
- 動機: 発案者の診断「本編は Lv 内で問題形式が一様なため、数字を変えて同じ計算を機械的に反復すれば数秒で解ける学習が成立し、構造を読まないまま高正答率で Lv を離脱できる」。小道が同じ罠を持たないかを攻撃的に検証した
- 方法: 各 Lv に対して「構造を読まない固定手続きソルバー」を敵として設計し、期待正答率を見積もる
- 帰結: roster 記載原則 6 (機械化耐性) を新設。各 draft は v0.2 で本監査の修正案を反映する

## 0. 結論 3 行

1. hayasa は 5 本中もっとも脆い。セット内の型分散を規定した行が doc 全体に 1 つも無く、Lv3 / Lv4 / Lv7 は構造を一切読まない単一手続きで 0.85 から 1.00 に達する。
2. kisokusei は対比ペアという装置を持つが、それが置かれているのは Lv3 と Lv10 の 2 か所だけで、単型のまま残った Lv5 / Lv8 / Lv9 が 0.82 から 1.00 で通過する。Lv8 は 5 問すべてが 1 公式の反復で、対策装置がゼロ。
3. 全 5 本に共通する設計上の贈り物が 3 つある。整列の一本鎖規則、選択肢位置の無規定、そして「一意性を保証するための固定語彙」。いずれも品質保証のために置かれた規則が、そのまま機械化の手がかりになっている。

## 1. 監査の枠組み

### 1.1 ソルバーの 2 層

| 層 | 定義 | 使える手がかり |
|---|---|---|
| T1 構造盲目 | 問題文のいかなるトークンにも分岐しない固定手続き | 出現した数の個数・大小・比、単位記号の見た目、形式 (UI から既知)、選択肢の形状、整列部品の数値連鎖 |
| T2 語彙ルックアップ | doc が固定表として明記した型語彙にのみ分岐する。それ以外は T1 と同じ | 上記 + 型語彙 3 から 4 語の対応表 |

T2 は厳密には構造盲目でないが、doc 自身が語彙を閉じた表に固定し validator で機械強制しているため、「1 回覚えれば理解なしに全問通る有限表」になっている。

### 1.2 9 割ゲートの実効閾値は 9 割ではない

komorebi/app.js の昇降 (10 問窓、9 以上で昇格、6 から 8 は据え置き、5 以下で降格) の通過確率:

| 真の正答率 p | 昇格確率 / 窓 | 降格確率 / 窓 | 期待昇格までの問数 |
|---:|---:|---:|---:|
| 0.90 | 0.74 | 0.00 | 14 |
| 0.85 | 0.54 | 0.01 | 19 |
| 0.80 | 0.38 | 0.03 | 27 |
| 0.75 | 0.24 | 0.08 | 41 |
| 0.70 | 0.15 | 0.15 | 均衡 |

均衡点は p ≈ 0.70。p = 0.75 のソルバーは 8 セット前後で確実に昇格する。判定は 0.90 以上を機械化可能、0.75 から 0.89 を部分的に可能、0.74 以下を耐性ありとした。実務上の警戒線は 0.75。

### 1.3 5 本に共通する構造的な穴

| # | 穴 | 根拠 | 影響 |
|---|---|---|---|
| C1 | 整列の一本鎖規則がそのままソルバーになる | hayasa 10 章検証 8「部品 k が部品 k-1 の出力値を含むこと」、kisokusei 10.4.6 同文 | 部品の先頭の数と末尾の数を照合して並べるだけで一意に決まる。文を読まない。hayasa Lv4/7/10、kisokusei Lv5/8/10、diagram の整列は T1 で 1.00 |
| C2 | 正解選択肢の位置分散が 5 本とも無規定 | 各 doc の validator 一覧に位置分布の検査項目が無い。例題は立式の正解が A、診断の正解が B に強く偏る | 既存生成器 (ratio / unit_convert) は shuffle を使う慣行だが、doc が要求していないので実装で落ちうる |
| C3 | 一意性のための固定語彙が完全な lookup table になる | kisokusei 10.4.1「この 3 語彙以外の言い回しを使わない」、hayasa 7 章のわざ表 (向かい合うと足す、下りは足す) | 型判別が 3 エントリの表引きに縮退し T2 が 1.00 になる。両 doc が潰したいと宣言した弱点 (場面ごとの暗記) と正面衝突 |
| C4 | セット内の型分散規則が hayasa / johou_seiri / diagram に存在しない | kisokusei は Lv3/10 のみ規定。ratio_forms 7.4 は規則があるが validator が検査しない | 本編の「Lv 内で問題形式が一様」がそのまま小道側に持ち越されている |

C3 と C4 は独立。対比ペアは「直前の計算の反復」を殺すが「語彙表を引く」ソルバーは殺さない。

### 2.5 kom_diagram_model

単独で 0.90 超の Lv は無いが形式単位で 3 つの穴: ①formulation は「区間長とラベル値の比が一定 + ラベル集合が本文の数と一致する図を選ぶ」幾何照合で誤りタイプの 4/5 が落ちる (Lv4/5 で最大 0.90) ②ordering は全問共通の固定動詞スキーマで 1.00 ③find_all は数値と図ラベルの照合で 0.90 以上。「正図は lengthOverride を持たない」+「誤図は不変条件をちょうど 1 つ破る」という品質規則の組が、正図 = 描画長がラベルに厳密比例する唯一の図、という手がかりを与えている。

## 4. 本編と実質同一の Lv

- 完全同一: kisokusei Lv1 = 本編 ueki Lv1 (題材・型・形式・kind すべて一致。doc も自己申告済み)
- 準同一 (形式配合の差が実効的にほぼゼロ): kisokusei Lv5 (shuuki)、Lv8 (kisokusei Lv2/3)、Lv9 (kisokusei Lv6)、Lv6 (shuuki Lv5/6)、Lv7 (houjin Lv2/6)。hayasa Lv3 は小道内の kom_unit_convert Lv1-3 と重複
- 構造の再生産: hayasa Lv1-9 (節 = Lv 帯で各 Lv が 1-2 型に閉じる)、diagram Lv1-9 (図型が Lv 固定)、johou_seiri Lv1-4 (問い方が Lv 固定)

## 5. 補足所見

1. hayasa 未確定 8 の懸念 (小道が本編を易しくしすぎる) は逆で、現状は「小道でも同じ機械化が成立する」方向。
2. kisokusei 未確定 3 (対比ペアの適用範囲) は「数値の新鮮さ」より優先度が高い。少なくとも Lv5 と Lv8 への拡張が必要。
3. johou_seiri Lv7 の ordering (部品に数値も連鎖も無く、順序が本文の意味からしか決まらない) が 5 本中最良の耐性。他カテゴリの整列改修の参照点にする。
4. ratio_forms はレイテンシ非利用のままだと、狙った弱点を持つ子と持たない子を最後まで区別できない。投入判断ではこちらが重い。
