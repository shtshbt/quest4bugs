# 小道の仮称 命名規約

版: v0.1 (2026-08-14)
親文書: `docs/komorebi_design.md` 決定 1 (名称階層)、`docs/komorebi_course_plans.md`

## 1. 前提

海外種の大半は日本語名も英語名も持たず、学名だけで通っている。設計 (決定 1) は学名のカタカナ転写を禁じているため、図鑑に出す名前はこちらで組み立てる。組み立てた名前は実在の和名と区別できないので、図鑑では必ず「（仮称）」を添え、学名と並べて表示する (bugs.js の `nameStatus: "provisional"`)。

命名は標本写真を見て行う。見た目を知らずに付けた名前は特徴と食い違い、図鑑として誤情報になる。写真が取れていない種は命名しない。

## 2. 名前の形

```
[修飾語 0 個以上] + [分類群の和名]
マダガスカル        オオ ゴキブリ
ギン ハネグロ      トンボ
カンムリ カレハ    カマキリ
```

- 末尾は必ず分類群の和名 (科の和名があれば科、無ければ目や大きな群の和名)
- 修飾語は写真から確認できる特徴 (色、模様、形、大きさ) と、地域名に限る
- 全体で 4 から 12 文字程度。子どもが読める長さにする

## 3. してはならないこと

1. **学名のカタカナ転写** (決定 1)。Nanos を「ナノス」としない
2. **写真で確認できない特徴を名前に入れる**。生態 (夜行性、食性) は標本写真から分からないので使わない。文献で確認できた場合のみ note に書く
3. **既存の和名との衝突**。bugs.js の全和名と突き合わせ、一致したら付け直す
4. **実在する別種の標準和名の流用**。日本の近縁種の和名をそのまま使うと、その種だと誤解される
5. **優劣や気味悪さを含む語**。ヘクソ、バカ、ゴミのような既存和名の慣行語であっても、新しく作る名前には使わない

## 4. 手順

1. 標本写真 (`zukan_cards/processed/*_L2_grade.webp`) を見る
2. 科の和名を確認する (bugs.js の `familyJa`。無ければ目の和名)
3. 写真から見て取れる特徴を 1 つか 2 つ選ぶ
4. 名前を組み、bugs.js の全和名と衝突しないことを確かめる
5. `colors` の 2 色も同じ写真から決める (パラメトリック描画のフォールバックに使う)
6. `nameStatus: "provisional"` を必ず立てる

## 5. 検証

- 和名の一意性 (既存 + 新規の全体で重複なし)
- `nameStatus` が provisional であること
- 名前の末尾が既知の分類群和名で終わること
- 学名が入っていること (仮称と学名は対で意味を持つ)
