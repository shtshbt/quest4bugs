# メダル経済と採集道具 設計書

- 版: v1.0
- 日付: 2026-08-17
- 親文書: `docs/komorebi_design.md` (6 章 コレクション)、`docs/komorebi_volume_zukan_design.md`、`docs/komorebi_release_linkage.md`、`docs/backlog.md` (farming 対策の記録)
- 役割: トロフィー層の再設計 (メダル化)、かがやきのうろ、採集道具、リセット周回の全決定を 1 枚で定める。2026-08-17 の設計対話で確定した内容の集約。

## 1. 背景と目的

トロフィーは表示専用 (捕獲抽選には一切影響しない) で、達成が何にも繋がらない袋小路だった。一方、こはく farming 事案 (低レベル英語の高速周回でこはくを稼ぎ、マダガスカルで呼ぶ) は、収集動機が学習を牽引できるほど強いこと、そして狙った種を選ぶ手段 (ターゲティング) への需要が満たされていないことを示した。

本設計は、達成 (安定した習熟) を唯一の裏付けとする通貨 = メダルと、その使い道 = 採集道具を導入し、komorebi の達成層に自前の背骨を与える。王者の道との連動はしない (追加自由の維持。`komorebi_volume_zukan_design.md` 1 章の判断を踏襲)。

## 2. 経済の全体像: 3 つのノブの直交性

| ノブ | 役割 | 供給源 |
|---|---|---|
| 正答ゲージ (8 問 1 匹) | 捕獲の基本供給 | 学習。迂回不能 |
| こはく | 抽選回数の追加 | 補正済みレートでの獲得 |
| 採集道具 | 抽選の方向 (どの虫か、新顔か) | メダル交換。消耗 |

どのノブも他の代替にならない。回数を買っても方向は買えず、方向を持っても供給はゲージから来る。farming は「回数の通貨が供給を代替できた」事故であり、直交を保つ限り同型の exploit は構造的に生じない。

### 経済の不変条件 (6 か条)

1. 8 問 1 匹のレートは不変。道具は分布のみ動かす
2. レアリティ表は不動。レア度の進行は pity の専管
3. メダルの鋳造源は習熟のみ。ログインボーナス・イベント配布で配らない
4. 残高ゼロの原則。メダルを保持する状態は存在しない (取得 = 即時交換)
5. 基本ループは道具なしで永久に無料。消耗品を基本捕獲の必需品にしない
6. コレクション (図鑑・捕獲済み) を奪う操作は存在しない

## 3. メダル

- 名称: トロフィー → メダル。種名付きの銘 (例: マダガスカルオオゴキブリのメダル)。代表種の割当規則は現行 (カテゴリの最終 Lv 帯を投入した volume の看板、trophies.js の対応表) を踏襲する
- 獲得条件: Lv10 クリア + 安定判定 (直近 20 問 70%、現行 STABILITY)。条件の構造 (Lv10 クリア + 直近窓の正答率) は今後何をリネームしても変更しない。閾値そのものは昇降帯に追従する調整値で、2026-09-01 に 85% から 70% へ下げた (komorebi_design 6.6)
- メダルの顔: trophies.js の goldSpecies() による金色 SVG をメダルの刻印面に流用する
- course 分離が鋳造管理を兼ねる: 各 profile は自分の course のカテゴリにのみアクセスするため、兄が k5 (九九系) を刈る経路は存在しない
- 額面: 全メダル等価。メダル 1 枚 = 道具 1 つの固定相場

## 4. かがやきのうろ

御神木のメニューとして新設する。

- 入口: 御神木パネルの一角にボタンとして追加する。かせきそうびと同じ配置パターンを踏襲し、新しい画面遷移文法を発明しない (2026-08-17 決定)
- メダルは取得した瞬間に捧げる。ポップアップで道具を 1 つ選んで授かる (即時交換)。財布・残高 UI は作らない
- 捧げたメダルは奉納記録として、かがやきのうろで一覧できる (銘、カテゴリ、周回数、日付、授かった道具)。獲得の記録は不滅で、周回は星で重なる
- 奉納数に応じてうろの輝きを物理的に変える (発光の強さ・範囲がメダル量に連動する。段階システムやレベル表示は作らず、見た目の連続変化に留める)
- データは append-only の奉納ログ ({cat, speciesId, lap, date, tool}) のみ。残高は存在しないため導出も不要

移行措置 (2026-08-17 決定): うろ公開前に成立した既存トロフィーは、うろの初回訪問時に遡及的に奉納できる (1 個 = メダル 1 枚)。獲得済みの金の虫表示はそのまま維持し、奉納しても消えない。即時交換の原則 (取得した瞬間に捧げる) は新規鋳造にのみ適用し、遡及分だけは初回訪問という 1 度きりの窓で受ける。先に Lv10 を安定させた子が、うろの実装を待ったという理由だけで道具を持てない状態を避けるため。

## 5. リセット周回

- Lv10 クリアから 7 日間 (既定。5 日は調整オプション) のロック経過後、そのカテゴリにリセットボタンが出現する
- ロック中もボタンの枠は出す (2026-09-01 追加)。押せない状態 (disabled) で、ごほうびの表示「メダル 2 まい」の位置に残り日数「あと N 日」を出す。明けたらごほうびの表示に入れ替わる。実装は `trophies.js` の `resetDaysLeft()` (端数は切り上げ。明ける前を「あと 0 日」と出すと押せそうに見えるため) と `app.js` の `resetChoiceHtml()`
- ロック中を可視にする理由: このロックは記録 142 で「可視の暦ゲート」であることを根拠に採用されたもの (安定判定への 3 日ルール案は不可視ゆえに不採用)。黙ってボタンを隠すと、Lv10 をクリアした本人には「クリアしたのに何も起きない日が続く」だけになり、不採用にしたはずの不可視の制約そのものになる。2026-08-17 の初期実装はロック中に空文字を返しており、この意図と食い違っていた
- タップでポップアップ: 「Lv1 にリセットしますか? リセットしてもういちど Lv10 になったら、メダルが 2 枚!」。選択は本人
- リセット周回 (2 周目以降) の鋳造は 2 枚 = 道具を 2 つ選ぶ。以後の周回も同条件 (7 日ロック + 2 枚)
- リセットされるのは Lv 進行のみ。図鑑・捕獲済み・奉納記録には一切触れない (不変条件 6)
- 設計判断: 週 1 回程度の全周回 (Lv1-10 + 安定判定 = 実質 100 問超の 70% 正答) は farming ではなく復習である。暦時間ロックが上限を定めるため、無限の蛇口は存在しない
- farming 耐性の根拠: (a) course 分離により低難度他 course の刈り取り経路がない、(b) 周回は 7 日ロックで暦ゲートされる、(c) 鋳造条件自体が安定 70% を要求する (2026-09-01 改訂。周回の総量 100 問超は変わらないため、farming 耐性の主因は暦ロックと course 分離のまま)
- インフレ監視: 演習ログ (q4b_import 経由) でメダル発行速度を観測し、過剰なら 3 周目以降を 1 枚に調整する (保留事項)

## 6. 採集道具 (11 種) と guild 対応

実在の採集法に対応させる。色分け等の恣意的対応は採らない。

判定は道具ではなく採集ギルド層 (`shared/species_guilds.js`) が持つ。道具は `guildKey` で 1 つを指すだけで、どの種がそのギルドかはギルド層が分類から導く (2026-09-06 分離。理由は 6.1)。

| 道具 | guildKey | 対象 guild | 主キー |
|---|---|---|---|
| ちょうネット | `butterfly` | 昼に とぶ チョウ | family (アゲハ・タテハ・シロチョウ・シジミ・セセリ + 昼行性のガ 3 科) |
| トンボ用メッシュネット | `dragonfly` | トンボ | order Odonata |
| 灯火採集セット | `nocturnal` | よるに とぶ 虫 | 鱗翅のうちチョウでないもの + 灯火に来る大型甲虫 (クワガタ・カブト・ゲンゴロウ) + トビケラ / ヘビトンボ / アミメカゲロウ |
| バナナトラップ | `sap` | きの しるに あつまる 虫 | family (クワガタ・コガネ (フン食を除く)・タテハ・ケシキスイ・ショウジョウバエ・ミバエ・スズメバチ) |
| スイーピングネット | `grassland` | くさはらの バッタや カメムシ | order Orthoptera + 陸生カメムシ + ハムシ / ゾウムシ + 花に来るハナアブ・ハナバチ・カリバチ |
| さかなとりあみ | `aquatic` | みずべの 虫 | 水生の科 (ゲンゴロウ・タガメ・アメンボ 等) + トビケラ / ヘビトンボ + 止水性のトンボ (ヤゴ) |
| ビーティングセット | `hidden` | えだに かくれる 虫 | order Phasmatodea / Mantodea / Araneae + 枝葉の甲虫とカメムシ |
| 吸虫管 | `tiny` | とても ちいさい 虫 | family (アリ・テントウ・ハムシ・ヨコバイ・アブラムシ 等) + sizeMm 上限 15mm (あれば) |
| 高所用長竿 | `canopy` | たかい ところの 虫 | family (セミ・ビワハゴロモ・ヨコバイ上科の大型・ヤママユ) + 属 (トリバネアゲハ・モルフォ・フタオチョウ 等) + 大型カミキリ |

| フントラップ | `dung` | ふんや しがいに あつまる 虫 | 属・亜科 (フンチュウ) + family (センチコガネ・シデムシ・エンマムシ・クロバエ・フンバエ) + ハネカクシ |

- 第 1 波の 11 種。第 2 波の 4 種は 6.3 にある。追加はギルド層に 1 ギルド足して `guildKey` を指すだけで済む
- volume freeze チェックリストに guild カバレッジ確認を追加する (`komorebi_release_linkage.md` 4 章)。下限を割った道具は交換画面でグレーアウト + 「この遠征では出番がない」注記
- 道具図鑑: 各道具の初回授与を記録する (11 種すべてを一度は授かる、という第二の完成目標)

### 6.1 ギルド層を分けた理由 (2026-09-06 決定)

当初の matcher は種データの `habitat` / `tags` / `sizeMm` を主キーにしていたが、実測すると次の穴があった。

| 事実 | 影響 |
|---|---|
| `canopy` / `treetop` / `arboreal` / `dung` 系の語が図鑑の語彙にほぼ無い | 高所用長竿の対象種が全 1950 種で 1 種、フントラップが 8 種 |
| `habitat` は 1397 / 1950 種、`subfamily` は 765 / 1950 種にしか無い | 巻ごとに埋まっている field が違い、当たり外れが巻で変わる |
| `sizeMm` はマダガスカル遠征 II (80 種) で 0 件 | 吸虫管が同巻で 0 種 |

いっぽう `order` / `family` / `scientificName` は全 1950 種にある (GBIF 由来なので新しい巻にも必ず入る)。そこで主キーを分類へ移し、`habitat` と `tags` は「あれば効く」補助キーとして残した。

種データへ語彙を書き足す案は採らなかった。1950 種へ遡って書いても、次の巻を取り込んだ瞬間にまた穴が開く (手で書いた語彙は新しい種に引き継がれない) ためで、分類から導けば新しい巻は取り込んだ時点でギルドが付く。

移行の結果 (2026-09-06 実測、5 巻 + 本編 3 教科の被覆):

| 道具 | 移行前 | 移行後 |
|---|---|---|
| 高所用長竿 | 全 DB 1 種。全 8 プールで下限割れ | 113 種。5 巻すべて + かんじで下限超え |
| フントラップ | 8 種。BO I 4.8% のみ | 53 種。MG II (公開回の巻) 5.0% + けいさん 7.7% |
| 落とし穴トラップ | 95 種。全巻で下限割れ | 202 種。AU I 以外の 4 巻で下限超え |
| 灯火採集セット | AU I 4.8% / BO I 1.2% / MG II 0% | AU I 8.3% / BO I 15.5% / MG II 12.5% |
| スイーピングネット | BO I 3.6% | BO I 23.8% |
| 吸虫管 | MG II 0% | MG II 28.8% |

どの道具の対象でもない種は 45 種から 4 種 (サソリ・カナヘビ・ヒキガエル・モズ = 昆虫以外の天敵枠) に減った。

### 6.2 道具どうしの境界 (2026-09-06)

重なりは許す。実際の採集も 1 種 1 法ではなく、バナナトラップのタテハは ちょうネットでも採れる。禁じるのは「A の対象が B にほとんど飲まれている」形で、そうなると A を装備する理由が B の下位互換しか残らない。上限は 80% とし、`tests/test_species_guilds.js` が全 55 組を見る。

移行の途中で実際に 2 か所そうなったので、境界を引き直した。

1. さかなとりあみ と トンボ用メッシュネット。`habitat` に水域名があるだけで水網に当たっていたため、トンボ 163 種のうち 139 種 (85%) が両方の対象だった。ヤゴをすくえる止水性 (pond / marsh / paddy / lake / wetland / bog) のトンボだけを水網へ残し、渓流性はメッシュネットの領分にした。重なりは 100 種 (61%) になった。トンボをまるごと外さないのは、6 章が さかなとりあみ の対象に「ヤゴ」を明記しているため
2. フントラップ と 落とし穴トラップ。フントラップは餌を入れた落とし穴でもあるので、対象 53 種のうち 51 種 (96%) が落とし穴と重なり、完全な下位互換になっていた。餌に来ることでしか捕まらない専門家 (フンチュウ・シデムシ・エンマムシ・クロバエ) を落とし穴から外し、餌なしの落とし穴には歩く虫 (オサムシ・アリ・コオロギ・ゴキブリ・ヒシバッタ・ツチカメムシ) を残した。重なりは 70% になった。ハネカクシだけは林床の徘徊性捕食者でもあるので両方に置く

フントラップの対象は「フンチュウ」から「ふんや しがいに あつまる 虫」へ広げた。実際のフントラップは餌に糞も死肉も使い、来るのはフン食の甲虫だけではない。図鑑のフン食甲虫は全 DB で 21 種しかなく、それだけでは巻あたりの下限に届かない。名前と絵は変えない。

### 6.3 第 2 波の 4 種 (2026-09-06 決定)

当初は 11 種で打ち止めとしていた。ギルド軸が飽和したかを実測で確かめたところ、飽和していたのは「届く範囲」のほうで (1950 種すべてが 11 種のどれかの対象)、切り口にはまだ空きがあった。飲み込み上限 80% を通った候補だけを 4 本採る。

| 更新 | 道具 | guildKey | 対象 | 効く場所 |
|---|---|---|---:|---|
| 6 | マレーゼトラップ | `malaise` | 144 | AU I / BO I / MG II / えいたんご |
| 6 | 材割りセット | `deadwood` | 171 | けいさん |
| 7 | サーバーネット | `stream` | 84 | MG I / BO I / MG II / えいたんご |
| 7 | 衝突板トラップ | `flight_beetle` | 262 | AU I / AU II / MG II / けいさん |

各更新に、小道の巻で働くもの 1 本と本編で働くもの 1 本を組にしてある。

マレーゼトラップは飛行路に張るテントで、樹冠の道具ではない (高さ 1 から 2 m の地上設置が標準形。ぶつかった虫が上へ登る習性を使い、最上部の瓶へ落とす)。高所は 高所用長竿 が持つ軸のまま。

4 本を入れるにあたって、既存 3 本から領分を分けてもらった。

| 削る側 | 渡す先 | 理由 |
|---|---|---|
| スイーピングネット | マレーゼ | 花に来るハチとハエを渡す。スイーピングは 497 種と 11 本中いちばん太く、えいたんごの半分 (50.6%) を 1 本で占めていた。渡したあとは 365 種、29.9% |
| ビーティングセット | 材割り | 幼虫が材を食う家系を渡す。枝を叩いて落ちてくるのは葉や生きた枝にいるもので、朽ち木の中のものは出てこない |
| さかなとりあみ | サーバーネット | 渓流にしかいない種を渡す。水網はたまり水をすくう道具で、ながれの石をおこす道具ではない |

削ったあとも、公開済みの 6 種はどのプールでも下限 (5%) を割っていない。

材割りセットには条件が 1 つ残る。けいさんでは 30.6% と主力になるが、小道の 5 巻すべてで 3.6% 以下 (ボルネオ遠征 I は 0 種)。いまの巻は成虫標本ベースでカマキリ・ナナフシ・セミ中心で、カミキリとクワガタがほとんど入っていない。更新 6 の巻を選ぶときに朽ち木性の種を意識して拾う必要があり、これは種選抜の条件になる。

### 6.4 検討して落とした候補と、再戦の条件 (2026-09-06 / 09-07)

同じ物差し (飲み込み上限 80% と対象率の下限 5%) で測って落ちたもの。落ちた理由には
3 通りあり、どれに当たるかで「いつなら復活できるか」が変わる。理由を消さずに残すのは、
次に同じ思いつきが出たときに測り直さずに済ませるため。

再戦の下限は場所で違う。小道の 1 巻 (80 から 84 種) なら 5 種前後、本編の 1 教科
(432 から 508 種) なら 22 から 26 種で 5% に届く。

#### A. 既存の道具に飲まれる (原理が重複している)

在庫が増えても解決しない。復活するとしたら、既存の道具の領分が変わったときか、
ギルドではない軸 (6.5 の mode) で出し直すときのいずれか。

| 候補 | 実測 | 再戦の条件 |
|---|---|---|
| 糖蜜トラップ | 186 種。ちょうネットと 61%、残りもバナナと灯火の内側 | バナナトラップから夜の樹液性を外して昼夜で割るなら成立しうる。ただし灯火とバナナの 2 本で既に昼夜が割れているので、3 本目の意味は薄い |
| 落ち葉ふるい (ツルグレン装置) | 90 種。吸虫管に 100% 内包 | 吸虫管を「植物上の微小」に狭めれば独立する。ただし試算では マダガスカル遠征 II の吸虫管が 23 種から 1 種へ落ちて死札になる (アリ 22 種がそちらへ移るため)。両方が半端になる取引 |
| 樹皮めくり | 73 種。スイーピングと 93% | 越冬という時期の軸を導入するなら独立しうる。いまの図鑑に季節の状態は無い |
| 黄色水盤トラップ | 53 種。スイーピングと 92% | マレーゼ導入後は そちらとも重なる。独立の見込みは薄い |
| アリの巣ほり | 69 種。吸虫管に 100% 内包 | アリだけを吸虫管から外せば独立するが、吸虫管の対象がアリに依存している巻がある (マダガスカル遠征 II) |
| 水中トラップ (ペットボトル) | 54 種。さかなとりあみに 100% 内包 | 止水と流水は既に さかなとりあみ と サーバーネット で割った。3 分割の余地は無い |

#### D. 林冠の足場 (2026-09-07 追記)

超高所に足場を組む手法は実在する。林冠ウォークウェイ (突出木のあいだに吊った吊り橋。
ボルネオの Danum Valley や Lambir Hills)、林冠クレーン (建設用タワークレーンとゴンドラ。
パナマや苫小牧)、樹上いかだ (Le Radeau des Cimes。飛行船で樹冠の上に降ろす膨張式の
いかだ) の 3 系統。

道具として測ると 3 通りとも通らなかった。

| 定義 | 対象 | 最大の重なり |
|---|---:|---|
| 樹冠ギルドそのまま | 113 | 高所用長竿 100% |
| 突出木だけ (70mm 以上の樹冠性) | 61 | 高所用長竿 100% |
| 樹冠に居て採るもの全部 | 566 | 灯火 38%。ただし全 DB の 29% で、中身は実質「森の虫ぜんぶ」 |

原因ははっきりしている。ウォークウェイは捕獲法ではなく足場で、上に登って何をするかは
叩く / なでる / 灯火を張る / 掬う のいずれか。高所用長竿が「下から届かせる」で樹冠の軸を
既に取っているぶん、足場をギルドにすると重なる。

再戦するなら 6.5 の mode 軸。装備中の道具に樹冠ギルドの重みを上乗せする「足場つきの
装備枠」(ビーティング + 足場 = 樹冠のナナフシ) にするか、道具ではなく巻が持つ地形の
属性にするかの 2 通りが考えられる。前者は装備 1 枠という前提から触ることになる。

### 6.5 第 3 波の方向 (2026-09-06 合意、設計は未着手)

ギルド軸 (どの虫か) は第 2 波で使い切りに近い。次は軸そのものを増やす。

たまごさがし / 幼虫さがし。装備中は捕獲がその種の卵になる。ギルドを持たないので `worksIn` の下限判定にかからず、対象ゼロも起きない。`metamorphosis` を持つ 1939 種すべてが対象になる。

決まっていること。

- ♂♀ をそろえる手順を迂回できるのは意図した効果として認める。そのぶん難易度は高くする
- 未捕獲種の卵も正式に許す

決まっていないこと (第 3 波の設計で扱う)。

- 交換レート。孵化まで 100 から 1000 正答かかるので、8 問 1 匹に対して素直にやると 12 倍以上の損になる。育てた虫の常時 HP+2 と色違い抽選で釣り合うかは balance の判断
- かせきのかけら経済との関係。いまの正規ルート (♂♀ 捕獲済み + かけら) を道具が迂回するので、こはく farming と同じ形の穴になりうる

## 7. 道具の仕様

- instance 制: 各個体が {種類, 残耐久} を持つ。同種複数所持可 (灯火セット 4 つはそれぞれ個別の耐久)
- 耐久: 100 捕獲 (全道具共通・全図鑑合計。2026-08-20 に 30 から引き上げ)。未装備の道具は減らない。減るのは捕獲 1 回につき 1 (ゲージ捕獲・こはく呼び出し共通)
- 装備は 1 枠。装備中の全捕獲抽選に自動適用される (komorebi のゲージ捕獲、こはく呼び出しの両方)
- こはく呼び出し画面にインライン道具ウィジェットを置く: 現在の装備を常時表示し、タップで なし / 所持道具に切替。既定値は現在装備 (通常ケースはゼロタップ)。yes/no のモーダルは作らない
- 捕獲リザルト画面に残耐久を小さく常時表示する (例: 🥅 12/100)。減る瞬間が常に見えることで「いつの間にか壊れた」不満を構造的に防ぐ
- 破損は小イベント: 「あみが やぶれた!」。同種の予備があれば自動持ち替え + 通知。狩りの途中で操作を要求しない
- スターター支給はしない。二人が同じルールでメダルを稼ぐ対称性を優先する

## 8. 抽選への効果

道具が動かすのは「どの虫か」と「新顔か」の 2 つ。レアリティ表は動かさない。

- guild 重み: 装備道具の対象 guild に一致する種の pickSpecies 重みを 3 倍 (排他にしない。抽選の意外性を残す)
- 未発見ブースト: 現行 drawCapture は同一 tier 内で未捕獲種を絶対優先するため、ダブりは「完成済み tier を引いた時」にのみ発生する。よって未発見ブーストは pity と同じ層 = 完成 tier から未完成 tier への振替確率に、道具装備中 +0.25 (上限 1.0) を加算する形で実装する。基礎レアリティ表 (pickTier) は触らない
- 子ども向けメッセージ: 「見たことない虫に であいやすくなりそうだ…!」(数学的に真実なので堂々と出す)

## 9. 演出

抽選の数学は重みでも、体験は道具ごとの採集シーンにする。

- 道具ごとの捕獲ビネット (SVG シーン): 灯火 = 夜景にライトが灯り虫が集まる、落とし穴 = 朝に見回りに行く、バナナトラップ = 樹液の様子を見に行く、さかなとりあみ = 水辺をすくう、等
- 道具アイコン SVG を 11 種ぶん生成する (交換画面・道具箱・装備ウィジェット・リザルト表示で共用)
- 破損イベント、初回授与 (道具図鑑登録)、うろの奉納にもそれぞれ小さな演出を当てる
