# 小道の遠征・図鑑・カテゴリの結びつき (2026-08-14 決定)

版: v1.0
親文書: `docs/komorebi_design.md` (決定 4、9)、`docs/komorebi_ui_design.md` 3 章と 5 章

## 1. 決定: 地域内共通プールは採用しない

検討した共通プール案 (地域の公開済み全巻を 1 つの抽選プールにする) は不採用とする。

理由は学習ドライブの構造にある。小道は王者の道と連動しておらず、「新しい図鑑 (巻) を開けたければ、その巻に紐づくカテゴリを触る」という結線が新規カテゴリへの唯一の誘導である。共通プールにすると、簡単な既習カテゴリの反復だけで新しい巻の図鑑が完成できてしまい、新カテゴリを触る理由が消える。分かりやすさと引き換えに学習側の背骨を失うため、採らない。

したがって抽選の境界は従来どおり**遠征 (volume) 単位**とする。遠征 II の種は、遠征 II に紐づくカテゴリの正答からしか捕れない。

## 2. 抽選の境界と閲覧の単位を分ける

共通プール案が魅力的に見えた理由 (分冊感の解消、取り残しの見通し) は、閲覧側だけで満たせる。抽選と閲覧は別の層である。

| 層 | 単位 | 役割 |
|---|---|---|
| 抽選 (捕獲) | 遠征 | 学習ドライブ。新カテゴリと新図鑑を結線する |
| 分母と完成 | 遠征 (freeze) | 決定 4 の完成感。I の 84/84 ✓ は II が来ても動かない |
| 閲覧 (図鑑) | 地域で一括 | 分冊感を消す。遠征は絞り込み条件の 1 つ |
| 総覧 | 小道全体 | 小道トップの共通図鑑。地域横断の眺め |

## 3. UI 仕様

### 3.1 カテゴリボタンに遠征番号を振る (①)

地域パネルのカテゴリボタンに、そのカテゴリが紐づく遠征の番号を badge で示す。

```text
マダガスカル
  [割合と比       Ⅰ]  [2の段暗唱  Ⅰ]  [連続九九  Ⅰ]
  [6の段暗唱      Ⅱ]  [九九の逆引き Ⅱ]
  遠征 Ⅰ: 84/84 ✓   遠征 Ⅱ: 23/100
```

- badge はローマ数字 (Ⅰ Ⅱ Ⅲ)。タップでそのカテゴリのセッションが始まり、捕獲はその遠征のプールから出る
- どのボタンがどの図鑑を増やすかが、始める前に 1 目で分かることが目的
- 遠征ごとのグループ見出しでも同じ情報を伝える (badge と併用)

### 3.2 地域図鑑は一括、遠征で絞り込み (②)

地域の図鑑は 1 冊として全巻を一括表示する。I/II/III という分割は恣意的な運用単位であって、子どもにとっての意味単位は「マダガスカルの虫」だからである。

- 既存の絞り込み列 (レア度 / なかま / つかまえたものだけ / なまえ) に**遠征チップ**を足す (Ⅰ / Ⅱ / Ⅲ)
- 進捗表示は遠征ごとの分母を並べる (決定 4 の凍結分母をそのまま見せる): `Ⅰ 84/84 ✓　Ⅱ 23/100`
- 合計 (107/184) も添える。合計は表示用で、完成判定はあくまで遠征ごと

### 3.3 小道の共通図鑑 (③)

小道トップ (世界地図の下、トロフィー入口の並び) に、全地域を横断する共通図鑑の入口を置く。

- 中身は全 volume の種の一括グリッド。絞り込みに**地域チップ**を足す (マダガスカル / オーストラリア / ...)
- 御神木パネルの「🌿 こもれび N/M」の N/M と同じ集計をここが担い、タップの着地先になる
- 読み物としての図鑑 (捕獲の場ではない)。ここから遠征ページへは飛ばない (地図が導線)

## 4. カテゴリの帰属規則

- 遠征の manifest がその遠征に紐づくカテゴリを列挙する (現行どおり)
- **地域内で同じカテゴリは 1 つの遠征にのみ属する** (badge の一意性のため)
- 各遠征の manifest には**両コース (k5 / k10) のカテゴリを最低 1 本ずつ**載せる。更新カレンダーには k10 の新カテゴリが無い更新があるため、その巻は既存 k10 カテゴリを復習枠として載せる。これが無いと k10 の子が新しい巻を一切掘れない

未決: 復習枠として載せたカテゴリが前の遠征にも属している場合の扱い (帰属を最新へ移すか、復習枠は badge を分けるか)。実装時に確定する。

## 5. 実装への影響

- 抽選まわりは変更なし (applyAnswer は volume 単位のまま)
- 地域パネル: 遠征グループ見出し + badge。ピンは地域 1 本にし、巻の選択はパネル側で行う
- 図鑑: `renderZukan` を地域単位へ (全公開巻の種を連結)、遠征チップを絞り込みへ追加
- 小道トップ: 共通図鑑の入口と一括グリッド (地域チップ付き)
- 検収 15.2 は現行のまま有効 (抽選境界は巻)
