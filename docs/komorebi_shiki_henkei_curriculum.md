## 1. ねらい

潰す弱点: □ のある式を、□ を求める式へ変形できない。□ の位置 (前か後ろか) と = の向き (左か右か) が変わると、どの数からどの数を引くのか、足すのかが決まらない (roster 2 章)。

躓きの実体を 3 つに分けて書く。

第一に、変形の規則が 1 本の近道に置き換わる。`24+□=35` のような形だけを続けて解くと、「□ を もとめるのは ひきざん」という規則ができる。この規則は `□-24=11` で外れる (答えは `11+24`)。たし算とひき算を両方見た子は「しきと ぎゃくの けいさん」という規則を作りやすい。これは `35-□=11` で外れる (答えは `35-11`)。「□ が まえに あれば たす」という規則は `□+24=35` で外れる。どの近道も手がかりを 1 つだけ見て残りを読まない。正しい規則は演算と □ の位置の 2 つを同時に読むことでしか決まらない。

第二に、その 2 つを結ぶ考え方が欠けている。たし算とひき算の式には必ず「ぜんぶ」(いちばん大きい量) が 1 つある。□ が ぜんぶなら片方どうしを足し、□ が片方なら ぜんぶから もう片方を引く。演算の記号ではなく「□ が ぜんぶか、片方か」で決める構えを渡すことが本カテゴリの目的であり、わざ (7 章) の中心に置く。

第三に、= を「こたえを かく あいず」と読み、変形を「えんざんを ぜんぶ ぎゃくに する」作業と思っている。`20+□=15+12` のように両側に式があると、むこう側の `15+12` の + まで ひっくり返したくなる (3.5 章の `flip_other_side`)。= は両側が同じ大きさであることを表す記号で、むこう側の式は 1 つの数として そのまま残る、という読み方を Lv3 から Lv9 の両側に式がある問題で入れる。

□ に入る数は答えさせない (Lv1 の導入だけが例外)。□ を求める式を、数のカードと + − のカードを枠に並べて組み立てさせ、組み立てた時点で終わりにする。選択肢から選ぶ形 (v0.2.1 まで) は、肢の集合の形そのものが型と答えを語ってしまうため廃止した (共通規則 C5)。組み立て式では、子どもが作った式そのものから誤りの型が決まる (3.5 章)。

## 3. 出題範囲と除外

出す: 加法と減法の □ のある等式の変形 (2 数の形は Lv2 から Lv4、両側に式がある形は Lv3 から Lv9)、= の左右が逆の等式、加減の 1 段の文から文の順の □ の式を組み立てること (Lv10)。Lv1 だけ、□ がひとりの式の値を答える。

出さない (理由付き):

- 乗法と除法。roster 3.15 章の範囲。
- 本文と正答の負の数。正答の式は左から計算した途中の値を含めて 0 以上にする。子どもが組み立てた式が負になるのは許し、誤りの型として記録する (3.5 章)。
- 100 を超える数。本文の数と □ の真の値を 100 以下にする (Lv2 は 20 以下、Lv10 は 30 以下)。
- 0。本文の数と □ の値は 2 以上とする。
- かっこ、片側に 3 つの項がある式 (`□+12+8=35`)。
- 両側の形の むこう側の差 (`□+5=47-19`)。v0.2 は Lv6 から入れていたが、v0.3 で外した。むこう側に差があると、□ の側の数とむこう側の数の大小が型と結びつく (C7。11.4 章)
- 2 数の形を Lv5 以降に出すこと (案 3)。
- 時間要素。

### 3.3 組み立ての画面と カード

| 族 | 枠 (左から) | 数のカード | 演算子のカード |
|---|---|---|---|
| 導入 (Lv1) | 組み立てなし。数字の入力欄 (既存の normal `num`) | なし | なし |
| 2 数 | `□ =` [数] [演算子] [数] | 本文の 2 数 | + と − |
| 両辺 | `□ =` [数] [演算子] [数] [演算子] [数] | 本文の 3 数 (a、b、c) | + と − |
| 文 | [数] [演算子] [数] `=` [数] | 本文の 2 数と □ のカード | + と − |

規則:

1. 数のカードは本文に出る数すべてで、1 枚ずつ。おとりのカードは置かない。理由は 3 つある。11.2 章のどの近道も本文の数だけを使うので、おとりは近道を止めない。枠を全部埋めないと出せないので、おとりを置くと「本文に無い数を使う」誤りが増えるが、変形の理解とは別の誤りである。数のカードの枚数が族ごとに一定なので、枚数は手がかりにならない。
2. 数のカードの並び順は、注入 `random` で問題ごとにシャッフルする (検証 12)。
3. 演算子のカードは + と − の 2 枚で、数のカードとは別の段に、いつも + 、− の順で置く。何度でも置ける。
4. 数のカードは 1 回だけ置ける。置いたカードは薄くなる。
5. カードをタップすると、同じ種類の空いている枠のうち いちばん左に入る。数の枠には数のカード (文では □ のカードも)、演算子の枠には演算子のカードだけが入る。
6. 置いた枠をタップすると、カードが戻る。「けす」で全部戻る。「できた」は枠が全部埋まったときだけ押せる。
7. 式の表示の引き算記号は − (U+2212) で出す。本書と生成器の内部表現は半角の `-` を使う。

### 3.4 判定と同値の扱い

組み立てた式を符号つきの項の列として読む。最初の項は +、以後は直前の演算子の符号を付ける。

正答の条件 (2 数と両辺):

1. 符号つきの項の組 (並びは問わない) が、3.1 章の正答の式の組と一致する。
2. 組み立てた並びのまま左から計算して、途中の値が 0 以上である。

1 を満たし 2 を満たさない並びは `negative_step` として不正解にする。本カテゴリは途中を含めて負にならない式だけを正答として扱ってきた (3 章) ので、それに合わせる。

型ごとの受け付ける並び (全列挙。両辺は a が最大の数なので、a を引く並びは a を最後に置く以外は途中で負になる。4.2 章の C7 の規則):

| 型 | 正答の項の組 | 受け付ける並び | `negative_step` になる並び |
|---|---|---|---|
| 2 数 T_AF、T_SB | {+y, -x} | `y-x` | なし (`-x` から始める並びは作れない) |
| 2 数 T_SF | {+a, +d} | `a+d`、`d+a` | なし |
| 両辺 T_AB、T_AF | {+b, +c, -a} | `b+c-a`、`c+b-a` | `b-a+c`、`c-a+b` |
| 両辺 T_SF | {+a, +b, +c} | 6 通りすべて | なし |
| 両辺 T_SB | {+a, -b, -c} | `a-b-c`、`a-c-b` | なし (最初の項が - になる並びは作れない) |

正答の条件 (文、Lv10): 組み立てた等式が、文の順の式 (3.1 章) と完全に一致する。たし算の入れかえ (`6+□=15`) や □ を求める式 (`15-6=□`) は、□ に真の値を入れると成り立つが、文の順ではないので `true_reordered` として不正解にし、解説カードで「しきは ただしいよ。おはなしの じゅんに ならべよう」と示す。Lv10 の練習内容は文の順に並べることそのものであり、□ を求める式は kom_equation_select Lv7 の領分である (2.2 章)。

#### 3.5.3 文

数の枠 3 つに、見えている 2 数 (文に出る順に K1、K2) と □ を並べ、演算子を 1 つ置く。作れる等式は 12 通りである。

1. 文の順の式と完全に一致すれば correct。
2. そうでなく、□ に真の値を入れると成り立てば `true_reordered`。
3. どちらでもなければ、次のうち当てはまるものをすべて付ける。演算子が動詞と逆なら `op_flip`。□ の場所が文と違えば `unknown_misplaced` (置いた場所も記録する)。K1 と K2 の順が文と逆なら `known_swap`。

2 数、導入、文の数は、表の条件を満たす組から型によらず一様に引く (2 数は 3 型が同じ (x, y) の分布を使い、型に応じて x と y を枠へ割り当てる)。

両辺の数の取り方は C7 による。生成の手順は次のとおり (生成器は条件で棄却してもよいが、得られる分布はこれと同じでなければならない)。

1. a を 20 から 45 から、d を 2 から 10 から一様に引く。
2. 型 (T_SF は罠かどうかも) から a と b + c の大小を決め、R = a - d (a > b + c のとき) か R = a + d (b + c > a のとき) とする。
3. b を 2 から R - 2 から一様に引き、c = R - b とする。
4. 3 数が互いに異なり、b と c が a より小さく、3 数の和が 42 から 88 に入るものだけを残す。

a と b + c の大小は、負の数を使わないかぎり算数が決める (`a+□=b+c` では b + c = □ + a なので b + c > a、`a-□=b+c` では a = □ + b + c なので a > b + c)。型から自由なのは T_SF だけで、v0.3.1 はその半分を a > b + c の罠にする (12.1 章)。この大小を固定すると、a の帯、d の帯、3 数の和の帯の分布は型によらない (検証 13)。大小の 2 群 (a > b + c の群と b + c > a の群) のあいだでは、和 = 2a ∓ d なので a の帯と和の帯の両方を同じにはできない。v0.3.1 は a の範囲と和の範囲の両方に端を設けて差を両方に分け、数の大きさを使う手続きが 0.75 を超えないところに置いた (11.3 章。a の範囲を 26 から 39 にして a の帯を 2 群でそろえる案は、op と和の組が 0.752 になったので採らなかった)。

v0.3 は T_SF にだけ a + b + c ≤ 100 の上限を課し、a の範囲も型ごとに違ったため、数の大きさだけで T_SF とそれ以外が分かれていた (再監査の N1)。

## 4. セット構成の規則

- 同じ本文の問題が同じセットに 2 問出ないこと (検証 9)。
- 隣どうしの両辺の問題は、P1 の 2 問を除き、同じ {b, c} (順を問わない) を持たないこと (検証 9)。P1 のペアの特徴 (前問と むこう側の式が同じ) が、ペアでない組で立たないようにするため (Phase 7 の M04)。満たさないときは、その問題の数だけを引き直す。

独立に抽選する理由は C6 と C7、および監査 5 章の 4 である。v0.2.1 のテンプレート (各型 1 問以上 2 問以下) と隣接禁止は、前問までの型から次の型を推せる手がかりになっており、何も読まない手続きが Lv4 で 0.757 に達した。監査の試算 (iid) でも独立抽選で 0.59 から 0.69 に下がっている。独立抽選では、あるセットにある型が 1 問も出ないことがある。型の比率は Lv 累計で守る (検証 8)。

比率の決め方は 4.4 章。

### 4.3 対比ペア

3.6 章の 2 型だけを使う。2 問目の型を 1 問目と独立に決めるので、ペアの 2 問の答えは同じこともある。ペアの役目は、同じ数を見て前問と同じ手続きを くり返す読み方を、答えが変わる組と変わらない組の両方で試すことにある。

### 4.4 比率の決め方 (段 A と段 B の床)

組み立て式の答えの種類は、2 数では「差」と「和」、両辺では「`b+c-a`」「`b+c+a`」「`a-b-c`」の 3 つである。答えの種類は □ の となりの演算 (op) と □ の位置 (pos) の 2 つで決まる。

| 型 | op | pos | 2 数の答え | 両辺の答え |
|---|---|---|---|---|
| T_AB | + | 後ろ | (出さない) | `b+c-a` |
| T_AF | + | 前 | 差 | `b+c-a` |
| T_SB | - | 後ろ | 差 | `a-b-c` |
| T_SF | - | 前 | 和 | `b+c+a` |

2 数 (Lv2): 3 つの近道 (いつも引く、ぎゃくの演算、□ が まえなら たす) は、それぞれ T_SF、T_SB、T_AF の 1 型だけで外れる。どの比率でも 3 つの最大値は 2/3 を下回れない。Lv2 は 3 型を 1/3 ずつにして、3 つの近道をそろって 0.667 にする。これが Lv2 の例外である (段 A と段 B の両方に適用し、上限は 0.70 未満。13 章の v0.2.1 と v0.3)。

両辺 (Lv5 から Lv9): 型の比率を T_AB を α_B、T_AF を α_F、T_SB を s、T_SF を f とする (α = α_B + α_F)。

- 段 A の「ぎゃくの演算」(+ なら `b+c-a`、- なら `b+c+a`) は T_SB でだけ外れ、正答率は 1 - s。0.60 未満にするには s > 0.40 が要る。
- 段 A の「□ が まえなら たす、うしろなら ひく」(前なら `b+c+a`、後ろなら `b+c-a`) の正答率は f + α_B。
- 段 B が op だけを手がかりに最適な答えを選ぶと、+ なら `b+c-a` (α)、- なら s と f の多いほう。正答率は α + max(s, f)。
- 段 B が pos だけを手がかりに選ぶと、max(α_F, f) + max(α_B, s)。

s を上げると段 A の「ぎゃくの演算」は下がるが、段 B の pos の値は上がる。2 つを同時に満たす窓は狭く、本書は α_B 0.03、α_F 0.26、s 0.43、f 0.28 を採った。理論値は、段 A の最大が 0.57 (ぎゃくの演算)、段 B の op が 0.72、pos が 0.71 である。T_AB (`a+□=b+c`) が 3% と少ないのは、T_AB を増やすと α が増えて段 B の op の値 (α + max(s, f)) がそのまま上がり、また s、f、α_F を減らす分だけ段 A の「ぎゃくの演算」(1 - s) か段 B の pos の値が上がるためである。v0.3 の本文は「pos の値を押し上げる」と書いていたが、式 max(α_F, f) + max(α_B, s) では α_B は s を超えないかぎり pos の値を変えない (再監査の N3)。

混合 (Lv3、Lv4): 2 数の族を 0.6 で抽選し、2 数の型を T_AF 0.26、T_SB 0.42、T_SF 0.32 にした。2 数の問題では「いつも引く」が 1 - 0.32 = 0.68、「ぎゃくの演算」が 1 - 0.42 = 0.58 になり、両辺の問題 (いつも引く は a が最大なので `a-b-c` を作って T_SB だけ当たり 0.43、ぎゃくの演算は 0.57) と混ぜて、どちらもセット全体で 0.60 を下回る。

除外: 0.75 の判定から除く手続きは 2 種類だけで、理由がそれぞれ違う (11.6 章)。第一は op と pos を両方読む手続きで、変形の規則そのものである (v0.2.1 の決定 4)。第二は op か pos のどちらか一方と数の大小 (2 数では □ の側の数と むこう側の数のどちらが大きいか、両辺では a と b + c のどちらが大きいか) を組む手続きで、技能ではなく、4 つの形が負の数を使わない算数の制約から大小と型を結びつけてしまうことの副産物である。これを数えると 0.75 未満が数学的に到達できない (11.6 章の証明)。数の大小を単独で使う手続き、数の大きさ (和、a の値) を使う手続き、op か pos を単独で、または数の大きさやペアや履歴と組んで使う手続きは、すべて段 B の敵に数える。除外の組 (op と pos、op と mag、pos と mag) を 1 つでも含む特徴の組は、ほかの特徴を足しても除く (特徴を足した組の値は元の組の値を下回らないので、足した組だけを判定に戻すと除外が意味を失う)。この境界は検証 22 の (2) にも書く。除外した組の値は 11.3 章に参考として示す。

### 11.6 判定から除く手続きと、その理由

判定から除くのは次の 2 種類だけである。

1. op と pos を両方読む手続き。答えの種類は op と pos の 2 つで決まり (4.4 章の表)、この手続きは変形の規則そのものである (v0.2.1 の決定 4)。実測 1.000。
2. op か pos のどちらか一方と、数の大小 (mag) を組む手続き。これは技能ではない。4 つの形が、負の数を使わない算数の制約によって、数の大小と型を結びつけてしまうことの副産物である (統括者の判断、2026-10-25)。`a+□=b+c` と `□+a=b+c` では b + c = □ + a なので必ず b + c > a、`a-□=b+c` では a = □ + b + c なので必ず a > b + c で、自由なのは `□-a=b+c` だけである。2 数でも、`□+x=y` は必ず □ の側が小さく、`y-□=x` は必ず □ の側が大きく、自由なのは `□-a=d` だけである。

2 を敵に数えると、0.75 未満は数学的に到達できない。両辺で示す。

- op と mag の手続きが迷うのは、op が - で a > b + c の問題だけである。そこには T_SB (答え `a-b-c`) と T_SF の罠 (答え `b+c+a`) が混ざり、手続きは多いほうを選ぶ。誤る割合は min(s, f p)。
- pos と mag の手続きが迷うのは、□ が前で b + c > a の問題だけである。そこには T_AF (答え `b+c-a`) と罠でない T_SF (答え `b+c+a`) が混ざる。誤る割合は min(α_F, f (1 - p))。後ろ (T_AB と T_SB) は mag で必ず分かれる。
- 2 つをどちらも 0.75 未満にするには、s > 0.25、α_F > 0.25、f p > 0.25、f (1 - p) > 0.25 が要る。後の 2 つから f > 0.5 となり、s + α_F + f > 1 となって比率の合計 1 と矛盾する。

2 数でも、`□-a=d` の a と d の大小の割合を q とすると、誤る割合は min(s₂, f₂ q) と min(α₂, f₂ (1 - q)) で、同じ理由で 0.75 未満にできない。Lv2 の例外 (0.70 未満) にも、この 2 つの組は含めない (実測 0.83 と 0.84)。

除く範囲の境界: 1 と 2 の組 (op と pos、op と mag、pos と mag) のいずれか 1 つでも含む特徴の組は、ほかの特徴 (size、amax、orient、card、pair、履歴) を足しても除く。たとえば op と mag と size、pos と mag と pair、op と pos と amax は除く (検証 22 の (2))。

除かない手続き: mag を単独で使う手続き、数の大きさ (size、amax) を使う手続き、op か pos を単独で、またはペアや履歴や数の大きさと組んで使う手続き (mag と組まないもの)。mag と数の大きさやペアの組 (mag と size など) も除かない。これらは段 B の判定に残し、11.3 章のとおりすべて 0.75 未満である。

除いた 2 の手続き (大小で決める子) を野放しにしないため、T_SF の半分を罠 (`□-30=5+3` のように a > b + c) にした。大小で決める子は罠で `a-b-c` を組み、`minuend_swap` として記録に残る (12.1 章の観測)。

### 11.7 残る残余

1. Lv2 の例外。2 数の答えは差か和かで、3 つの近道がそろって 0.667 になる。12.1 章で見張る。
2. Lv3 から Lv9 の余裕が小さい。段 A は 0.57 から 0.58、段 B は 0.72 から 0.73 (最大は Lv4 の 0.734)。比率や数の取り方を動かすときは、監査の生成器で測り直す。

4. T_AB (`a+□=b+c`) が 3% と少ない (4.4 章)。
