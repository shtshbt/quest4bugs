## 3. 項目 2: 付録 A の 50 問

50 問を、検証 1、2、3、5、6、7、8、10、11、13、14、15、20、22、23、24、25 (肢の数と範囲)、27、29、30、33、39、43 のうちセット単位と問題単位で判定できるものに通した。人名の規則 (3.6 章) は 50 問すべてで満たしていた。家族が 2 人の問題は A.1 の 3 番と A.10 の 5 番の 2 問だけである。確かめの注記の数値は 79 項目を検算し、外れは 2 項目だった。

### U06 Lv1 と Lv2 で `h8` と `h10` がセットに 3 回出る

A.1 は `h8` が 3 回 (1、3、5 番)、`h10` が 3 回、A.2 は `h10` が 3 回 (2、3、5 番) で、4.5 章の「同一セット内で同じ言い回し id を 3 回以上使わない」を破る。これは付録の作り方の問題ではなく、規則どうしの衝突である。Lv1 は 5 問とも 2 人の have の本文で、4.4 章の 4 は その 7 割に `h8` と `h10` の対を求める。対を 3 組置けば `h8` と `h10` はそれぞれ 3 回になるので、4.5 章の上限の下では対はセットに 2 組まで、プール全体でも 0.4 にしかならない。

直し方: 4.5 章の上限の対象から `h8` と `h10` を外す (対の割合は検証 18 で別に見る) か、上限を問題の数で数える形にする。どちらかに決めてから、検証 13 と 4.4 章の 4 の文を合わせる。

### U07 はじめの数の文の言い回し id が定まらず、4.5 章の上限を破る

9.3 章の問題オブジェクトの例は、「さくらさんは あめを 9こ、ゆうとくんは 5こ もっていました」を `wordings: ["h1", "h1", "t1"]` と、`h1` 2 つで数える。この数え方では A.3 から A.10 の 8 セットすべてで `h1` が 3 回以上になる (A.3 は 6 回、A.6 は 13 回、A.7 は 11 回)。まとめた 1 文を 1 回と数えても 8 セットとも 3 回以上 (3 回から 7 回) である。受け渡しのはじめの数を 3 人分述べる文は、3.4 章のどの言い回しにも当たらない形 (3 人を読点で並べる) でもある。

直し方: はじめの数を並べる文に専用の id (例 `h0`) を与え、4.5 章の上限の数え方から外す。9.3 章の例をその id に直す。

### U08 A.2 の 3 番の 2 人の全体が奇数

A.2 の 3 番 (`split_who`) は全体 9 で、9.2 章の「split 2 人の全体 T は 6 から 18 の偶数」を破る。6 章 Lv2 例 4 (全体 9) も同じである。

直し方: A.2 の 3 番は全体 10、みおさん 6 こ (ゆうとくん 4 こ) にする。6 章 Lv2 例 4 も全体を偶数にする。

### U09 A.9 の 3 番の 3 人の数が重なる

A.9 の 3 番 (`split_used`) は はなこさん 4、りこさん 3 で、さいとくん は 10 − 4 − 3 = 3 になり、りこさん と同じ数になる。9.2 章の「split 3 人の全体 T は各人 1 以上、互いに異なる」を破る。6 章 Lv9 例 1 (そうたくん 3、りこさん 3) も同じである。

直し方: はなこさん を 5 にする (さいとくん 2)。候補 7、6、8、10、5、3 は互いに異なる。

### U10 A.9 の 5 番の W14 が成り立たない (8.1 章 5a の根拠例)

A.9 の 5 番 (`split_most`、`down`) の確かめは「ビーだま の 5 を さくらさん の数と読むと あおいさん が いちばん すくない人になる」と書く。実際には さくらさん 5、あおいさん 3 から しょうたくん は 9 − 5 − 3 = 1 になり、いちばん すくないのは しょうたくん である。8.1 章の順では しょうたくん は W7、あおいさん はどの型にも当たらず W18 になる。13 章 v0.4 と A.11 の 1 は、この例を根拠に 8.1 章へ 5a を足している。

直し方: A.9 の 5 番の数を、W14 の人が別の人になる組に替える。スクリプトで探した例: おはじき 9 こ、さくらさん は おはじき 1 こ と ビーだま 3 こ、あおいさん 2 こ (しょうたくん 6 こ)。`down` の答えは さくらさん、しょうたくん は W7、あおいさん は W14 になる (ビーだま 3 を さくらさん の数と読むと しょうたくん 4、いちばん すくないのは あおいさん)。確かめと A.11 の 1 の文も直す。

### U11 A.4 の 4 番の W21 が成り立たない

A.4 の 4 番 (`rel_most`、`down`) は ゆうとくん に W21 を付ける。W21 は「2 つの関係のうち 1 つ目だけを読み、その大きい側 (または小さい側) を答える」で、1 つ目の文「ゆうとくんは りこさんより おおく もっています」の小さい側は りこさん、つまり正解である。ゆうとくん は 8.1 章の順で W18 になる。

直し方: 2 つの比べる文の順を入れかえる (1 つ目を「ゆうとくんより そうたくんの ほうが おおく もっています」にする)。1 つ目の小さい側が ゆうとくん になり、W21 が成り立つ。

### U12 A.8 の 3 番の あおいさん は W17

A.8 の 3 番 (`split_most`、`up`) は、数の出ていない あおいさん に W18 を付ける。8 章の W17 は「全体の数を数の出ていない人か、全体と同じ節に名前のある人に結んで選ぶ」で、全体の 12 を あおいさん に結ぶと あおいさん が いちばん おおい。8.1 章の順でも W10 と W18 より前に当たる。

直し方: あおいさん を W17 にする (はなこさん と 2 人とも W17)。人の肢は単射を求めない (4.9 章) ので、そのままでよい。

### U13 8.1 章の順では 2 人の `split_who` の誤答が W7 になる

8.1 章は W7 (比べる向きが逆) を 3 番目、W17 を 6 番目、W10 を 7 番目に置く。2 人の `split_who` では誤答の 1 人は、いつも問いの向きを逆に読んだときの答えなので、8.1 章に従えば W7 が先に当たる。付録 A の A.2 の 3 番 (ゆうとくん に W17) と A.3 の 4 番 (ゆきこさん に W10)、6 章 Lv2 例 4 (みおさん に W17) は 8.1 章と食い違う。3 人以上でも同じことが起きる。6 章 Lv5 例 2 の はなこさん は いちばん すくない人で W7 に当たるが、本文は「8.1 章の優先順で W17」と書く。6 章 Lv10 例 4 の ゆうとくん (はじめの いちばん すくない人) も W7 に当たるが、W18 と書かれている。

## 8. 誤答の型と 7.2 章の一言の対応

W19 の一言は「ほかの ひとの ぶんも ひこう」である。`split_part` は問われた人の数が文に出ている問題で、ひき算は要らない。A.8 の 4 が該当する。直し方: `split_part` の W19 に「〈ひと〉の かずは ぶんに かいて あるよ」のような一言を置く。
